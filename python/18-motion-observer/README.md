## 一句話重點

把速度回授從「編碼器差分」換成「Luenberger 觀測器的 $\hat\omega$」,同一顆編碼器、同樣的增益,
轉矩雜訊直接降 40 倍 —— 觀測器靠模型 + 轉矩命令預測速度,不必像低通那樣用相位落後換平滑。

## 學習目標

1. 把第 10 章的觀測器放進**閉迴路**:速度回授改用 $\hat{\omega}$。
2. 量化效益:同樣增益下**轉矩雜訊降一個數量級以上**。
3. 理解為什麼觀測器優於低通:用「模型 + 轉矩命令」預測,**不用等量測** —— 沒有濾波器的相位代價。
4. 驗證差分回授的轉矩雜訊與第 14 章公式相符:$\sigma_u \approx k_p\cdot q/(\sqrt6\,T_s)$。

## 理論重點

### 架構

```
        ┌──────────── DiscretePID ◄─── ŵ ────────────┐
        u(轉矩命令)                          Luenberger 觀測器
        ├──────────────► 馬達 ──► 編碼器(量化位置)──┤
        └──────────────────────────────────────────►(u 也餵給觀測器)
```

### 差分回授的雜訊稅

第 14 章:差分速度雜訊 $\sigma_{\hat\omega} \approx q/(\sqrt6 T_s)$。它經過速度控制器的比例項直接進入轉矩命令:

$$\sigma_u \approx k_p\,\frac{q}{\sqrt6\,T_s}$$

2500 線(10000 counts/rev)、1 kHz 下 $q/(\sqrt6T_s) = 0.2565$ rad/s,$k_p = 0.5$ 就有約 0.13 Nm 的轉矩雜訊 ——
**增益越高、雜訊越炸**,馬達發熱、可聽見嘶聲。

### 觀測器:模型預測 + 量測修正

受控體模型 $\dot x = Ax + Bu$,$x = [\theta,\ \omega]^T$,量測 $y = \theta_q$:

$$A = \begin{bmatrix}0 & 1\\ 0 & -b/J\end{bmatrix},\quad B = \begin{bmatrix}0\\ 1/J\end{bmatrix},\quad C = \begin{bmatrix}1 & 0\end{bmatrix}$$

$$\dot{\hat x} = A\hat x + Bu + L\,(y - C\hat x)$$

以極點配置把 $A - LC$ 的極點放在 −200、−220 rad/s,得 $L \approx [415,\ 41925]^T$。
估測誤差 $e = x - \hat x$ 滿足 $\dot e = (A-LC)e$ —— **與命令 $u$ 無關**。只要模型準,
轉矩命令造成的速度變化被 $Bu$ 項「預先算好」,$\hat\omega$ 不會落後;只有模型誤差與擾動需要靠量測修正。

量化雜訊 $\varepsilon$ 從 innovation 進入觀測器,到 $\hat\omega$ 的路徑在高頻像 $L_2/s$ 一樣衰減;
而差分等於乘上 $s$,在高頻放大 —— 兩者的雜訊差一個數量級以上就是這個原因。

### 與低通濾波的差別

「差分 + 低通」也能降雜訊,但低通對**所有**速度變化一視同仁地延遲,相位落後進入迴路、吃掉相位邊限;
觀測器只對「模型沒預測到的部分」做濾波。這就是 Ellis 說的:觀測器讓你**買得起**更高的增益。

## 實驗設計

| 項目 | 設定 |
|---|---|
| 受控體 | `MotorPlant(J=0.002, b=0.01)`,1 kHz,模擬 2 s |
| 編碼器 | 2500 線(10000 counts/rev),$q = 6.28\times10^{-4}$ rad |
| 速度控制器 | `DiscretePID(kp, ki=5)`,命令 1 rad/s 步階 |
| 回授 A(FD) | $(\theta_{q,k} - \theta_{q,k-1})/T_s$ |
| 回授 B(觀測器) | 前向 Euler 離散化的 Luenberger 觀測器,極點 −200、−220 rad/s,輸入為上一拍轉矩命令 |
| 統計 | $t \ge 1$ s(穩態)轉矩命令的標準差 |

### 實驗 1:同一增益的迴路對決

$k_p = 0.5$,分別以 FD 與觀測器回授跑閉迴路,比較回授訊號、轉矩命令雜訊與實際速度平均值。

### 實驗 2:雜訊 vs 增益

$k_p \in \{0.25, 0.5, 1.0, 1.5\}$,兩種回授各跑一次,並與 $k_p q/(\sqrt6 T_s)$ 對照。

## 結果

| $k_p$ | FD 轉矩雜訊 [Nm] | 觀測器 [Nm] | 比值 | 理論 $k_pq/(\sqrt6T_s)$ |
|---:|---:|---:|---:|---:|
| 0.25 | 0.0764 | 0.0018 | 43.5 | 0.0641 |
| 0.5 | 0.1536 | 0.0036 | 43.0 | 0.1283 |
| 1.0 | 0.3080 | 0.0077 | 40.2 | 0.2565 |
| 1.5 | 0.4975 | 0.0125 | 39.8 | 0.3848 |

(理論欄由公式計算;notebook 以虛線畫在圖上,C++ 版直接印在表中。)

- **$k_p = 0.5$:轉矩雜訊 0.1536 → 0.0036 Nm,改善 43 倍**,而且兩種回授的實際平均速度都到 1 rad/s(驗證條件確認)。
- **FD 雜訊與 $k_p$ 成正比**,落在理論值的 1.2~1.3 倍:公式只算了「量測雜訊 × $k_p$」的開迴路路徑,
  閉迴路裡雜訊驅動馬達、再被量回來,加上積分項的貢獻,實際略高;$k_p$ 越大迴路回灌越多,倍數也略增。
- **觀測器雜訊同樣隨 $k_p$ 線性成長**,但基準低了 40 倍:比值在 40~43 之間幾乎不變,
  說明改善來自回授訊號本身的品質,與增益無關。
- 換句話說:觀測器回授在 $k_p = 1.5$ 時的轉矩雜訊(0.0125)仍比 FD 在 $k_p = 0.25$(0.0764)小 6 倍 ——
  **同一顆編碼器可以撐起高得多的迴路增益**。

## ✅ 驗證條件

| 條件 | 意義 |
|---|---|
| $k_p=0.5$ 時觀測器雜訊 < FD / 10 | 至少改善一個數量級 |
| 觀測器回授的平均速度與 1 相差 < 0.01 | 追蹤性能沒有犧牲 |
| FD 回授的平均速度與 1 相差 < 0.02 | (平均;瞬時值受雜訊擾動) |
| 四個 $k_p$ 下觀測器雜訊皆 < FD / 5 | 改善在所有增益都成立 |
| 四個 $k_p$ 下 FD 雜訊 / 理論 ∈ (0.3, 3) | FD 雜訊與 $k_pq/(\sqrt6T_s)$ 同量級 |

## 工程意義與常見誤區

- **觀測器不是「比較高級的低通」**:低通對命令與雜訊一視同仁;觀測器用轉矩命令預測運動,只濾「預測不到的部分」,所以沒有低通的相位代價(練習 3)。
- **模型誤差的代價比想像小**:$J$ 錯 30% 時,命令造成的運動預測有偏差,但 innovation 會把它修回來;
  代價是暫態估測誤差,而不是發散(練習 1)。實務上 $J$ 通常用第 13 章的方法量到 10% 以內。
- **觀測器極點不是越快越好**:極點越快,$L$ 越大,量化雜訊穿透越多 —— 又回到差分的老路;
  太慢則對擾動與模型誤差反應遲鈍。−200 rad/s 級大約是速度迴路頻寬的數倍,是常見起點(練習 2)。
- **擾動響應**:負載轉矩不在模型裡,觀測器要靠 innovation 才「看到」它,
  但只要觀測器頻寬高於速度迴路,迴路的擾動響應幾乎不受影響(練習 4)。進一步可加擾動狀態(第 10 章的擾動觀測器)。
- **一定要把實際送出的 $u$ 餵給觀測器**:若控制器輸出有飽和,要用飽和後的值,否則觀測器會以為馬達在做它沒做的事。
