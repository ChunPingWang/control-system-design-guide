## 一句話重點

Bode 圖把「迴路穩不穩、有多穩、追多快」一次攤開:開迴路 $L$ 的相位邊限告訴你離不穩定還有多遠,閉迴路 $T$ 的 −3 dB 頻寬告訴你能追多快 —— 而這兩者都能在實機上用 DSA **量測**出來。

## 學習目標

1. 讀懂開迴路 Bode 圖,並求出**增益邊限(GM)**與**相位邊限(PM)**。
2. 理解閉迴路**頻寬(bandwidth)**與**峰值(peaking)**,以及它們和開迴路穿越頻率的關係。
3. 用「量測」方式(DSA:chirp 激發 + 交叉頻譜)得到頻率響應,並與解析解交叉驗證。
4. 學會用 **coherence** 判斷量測資料哪些頻段可信。

## 理論重點

### 開迴路、閉迴路與邊限

```
 r ──►(+)──e──► [C(s) = 0.5 + 5/s] ──u(轉矩)──► [P(s) = 1/(Js+b)] ──┬──► ω(速度)
      ▲-                                                          │
      └───────────────────────────────────────────────────────────┘
```

開迴路 $L(s) = C(s)P(s)$,閉迴路 $T(s) = \dfrac{L}{1+L}$。本章系統代入數字:

$$L(s) = \frac{0.5s + 5}{s\,(0.002s + 0.01)} = \frac{250\,(s+10)}{s\,(s+5)}$$

- **增益穿越頻率** $\omega_c$:$|L(j\omega_c)| = 1$(0 dB)。高頻時 $L \approx k_p/(Js)$,故 $\omega_c \approx k_p/J = 250$ rad/s ≈ **39.8 Hz**。
- **相位邊限** $PM = 180° + \angle L(j\omega_c)$:穿越點離 −180° 還有多少相位。
- **增益邊限** $GM = -20\log_{10}|L(j\omega_{180})|$,$\omega_{180}$ 為相位穿越 −180° 的頻率。

本迴路相位 = 積分器 −90° + 零點(10 rad/s)+ 極點(5 rad/s),零極點幾乎互相抵銷,
最大額外落後只有約 19.5°(在 $\omega=\sqrt{50}$ rad/s),相位**永遠到不了 −180°** → $GM = \infty$。
在 $\omega_c$ 處:$\angle L = -90° + \tan^{-1}(250/10) - \tan^{-1}(250/5) \approx -91.1°$ → $PM \approx 88.9°$。

### 閉迴路頻寬與峰值

$$T(s) = \frac{250(s+10)}{s^2 + 255s + 2500}, \quad \text{極點} \approx -10.2,\ -244.8\ \text{rad/s}$$

慢極點 −10.2 幾乎被零點 −10 抵銷,$T$ 的行為接近一階系統 $\frac{245}{s+245}$,
所以 −3 dB 頻寬 ≈ 穿越頻率(約 40 Hz),且**沒有峰值**(PM 接近 90° 的迴路不會 peaking)。
PM 越小,$|T|$ 在 $\omega_c$ 附近的峰值越高,時域 overshoot 越大 —— 第 3、4 章會看到。

### DSA:用量測取得頻率響應

實機上沒有解析模型,只能**激發 + 量測**。以 Welch 交叉頻譜估計:

$$\hat H(f) = \frac{P_{ry}(f)}{P_{rr}(f)}, \qquad \gamma^2(f) = \frac{|P_{ry}|^2}{P_{rr}P_{yy}} \in [0,1]$$

coherence $\gamma^2$ 接近 1 表示輸出幾乎完全由激發線性解釋;雜訊、非線性或激發能量不足時會下降。
本章只採用 $\gamma^2 > 0.95$ 的頻點。

| DSA 模擬 | 5 kHz 離散迴路(`DiscretePID` + `MotorPlant`),對數 chirp 1 → 300 Hz、20 s、振幅 1 |
| FRF 估計 | `measure_frf()`:Hann 窗、`nperseg = 4096`(頻率解析度 5000/4096 ≈ 1.22 Hz) |

### 實驗 1:解析 Bode 與邊限

畫出 $L$ 與 $T$ 的 Bode 圖,標出 0 dB 線、−180° 線與穿越頻率,計算 GM / PM / 頻寬。

### 實驗 2:DSA chirp 量測

把 chirp 當速度命令 $r$ 注入離散閉迴路,記錄 $\omega$,以 $\hat T = P_{ry}/P_{rr}$ 估計閉迴路 FRF,
與解析 $T(s)$ 疊圖,並從量測資料中找出第一個 $|\hat T| < -3$ dB 的頻點作為量測頻寬。

## 結果

| 指標 | 數值 |
|---|---:|
| 增益邊限 GM | ∞ |
| 相位邊限 PM | 88.86° |
| 穿越頻率 $f_c$ | 39.81 Hz |
| 閉迴路 −3 dB 頻寬(解析) | 40.5 Hz |
| 閉迴路 −3 dB 頻寬(DSA 量測) | 42.7 Hz |

- PM ≈ 89°、GM = ∞:這是一個極度保守、非常穩的迴路(對照第 3 章調到 PM ≈ 54°)。
- 頻寬 40.5 Hz 與穿越頻率 39.8 Hz 幾乎相同 —— 高 PM 迴路「頻寬 ≈ 穿越頻率」的經驗法則成立。
- DSA 量測頻寬 42.7 Hz,比解析值高約 5%。原因有二:(1)頻率解析度只有 ≈ 1.22 Hz,
  量測頻寬只能落在頻點上;(2)離散迴路有取樣延遲,穿越附近相位稍少、$|T|$ 略微抬高,
  −3 dB 點往高頻移。高頻相位差同樣來自取樣延遲(第 4 章主題)。

## ✅ 驗證條件

| 條件 | 意義 |
|---|---|
| 85° < PM < 92° | PI 速度迴路 PM ≈ 89°,數值與手算一致 |
| GM = ∞ | 相位永遠不到 −180°,增益再大也不會(在連續模型中)不穩 |
| 35 Hz < 頻寬 < 46 Hz | 頻寬 ≈ $k_p/(2\pi J)$ ≈ 40 Hz |
| \|量測頻寬 − 解析頻寬\| / 解析頻寬 < 30% | DSA 量測方法可信 |
| 5 Hz 以下量測 \|T\| 皆在 ±1 dB 內 | 低頻命令完全追得上(積分器使 $T(0)=1$) |

## 工程意義與常見誤區

- **GM = ∞ 不代表可以無限加增益**:那只是連續模型的結論。真實迴路有取樣延遲、感測器濾波、
  機構共振,相位遲早會越過 −180°(第 4、16 章)。
- **頻寬 ≠ 穿越頻率**:只有 PM 高時兩者接近;PM 低時閉迴路會 peaking,−3 dB 頻寬會明顯高於穿越頻率,
  但那是「用振鈴換來的頻寬」,不是好事。
- **量測一定要看 coherence**:coherence 低的頻點(激發能量不足、雜訊、非線性)畫出來的 Bode 是假的。
- **在閉迴路上量測**:本章量的是 $T = Y/R$。若要量開迴路 $L$,要在控制器輸出疊加激發、量 $y/u$(練習 2),
  這也是實機 DSA 的標準做法 —— 不用把迴路打開。
