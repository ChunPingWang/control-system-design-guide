## 一句話重點

馬達與負載之間的軸是彈簧:共振之上負載「脫鉤」,馬達只看到自己的慣量 $J_m$,
迴路增益被抬高 $(1+J_l/J_m)$ 倍、第二交越頻率被推進延遲的死亡區 —— 可用增益因此掉一個數量級,濾波器救不太回來,機構才是解方。

## 學習目標

1. 認識 two-mass 系統的 Bode 特徵:**反共振谷 + 共振峰**,以及共振之上增益抬升 $(1+J_l/J_m)$ 倍。
2. 量化共振對**可用增益上限**的破壞。
3. 比較解方:notch、低通、機構改善(慣量比)—— 用同一把尺($k_{p,max}$)。
4. 從失穩振盪頻率反推機制:它發生在**第二交越** $k_p/(2\pi J_m)$,而不是共振頻率本身。

## 理論重點

### Two-mass 模型

```
  T ──► [ Jm ] ──── ks, cs(柔性軸)──── [ Jl ]
          │ωm(馬達端編碼器,collocated)        │ωl(負載)
```

$$J_m\dot\omega_m = T - k_s(\theta_m-\theta_l) - c_s(\omega_m-\omega_l),\qquad
J_l\dot\omega_l = k_s(\theta_m-\theta_l) + c_s(\omega_m-\omega_l)$$

轉矩 → 馬達速度的轉移函數:

$$P(s) = \frac{\Omega_m}{T} = \frac{J_l s^2 + c_s s + k_s}{s\left[J_mJ_l s^2 + (J_m+J_l)c_s s + (J_m+J_l)k_s\right]}$$

- **反共振**(分子零點):$\omega_{ar} = \sqrt{k_s/J_l}$ —— 負載像吸振器,把馬達「定住」。
- **共振**(分母極點):$\omega_r = \sqrt{k_s\dfrac{J_m+J_l}{J_mJ_l}} = \omega_{ar}\sqrt{1+J_l/J_m}$。

### 三段式的增益

| 頻段 | $P(s)$ 近似 | 意義 |
|---|---|---|
| $\omega \ll \omega_{ar}$ | $\dfrac{1}{(J_m+J_l)s}$ | 剛體,總慣量 |
| $\omega_{ar} < \omega < \omega_r$ | 谷 → 峰 | 反共振/共振對 |
| $\omega \gg \omega_r$ | $\dfrac{1}{J_m s}$ | 負載脫鉤,只剩馬達慣量 |

高頻比低頻多出的增益:$20\log_{10}\dfrac{J_m+J_l}{J_m} = 20\log_{10}(1+J_l/J_m)$。慣量比 9 → **+20 dB**。

### 為什麼共振砍增益:第二交越

P 為主的速度迴路 $L(s) \approx k_p P(s)$。剛體時交越在 $f_c = k_p/(2\pi J)$;
two-mass 在共振之上的增益大 10 倍,迴路增益在共振之後**再次穿越 0 dB**,位置在

$$f_{c2} \approx \frac{k_p}{2\pi J_m}$$

那裡的相位由取樣/計算延遲決定(每 Hz 都被延遲吃相位)。要讓 $f_{c2}$ 回到剛體時的安全頻率,$k_p$ 必須縮小約 $J/J_m = 10$ 倍。

### 解方的比較

- **Notch**:在 $\omega_r$ 挖掉共振峰,但它只影響一個窄頻帶;「共振之上整段抬升 20 dB」它管不到。
- **低通**:把高頻增益壓下去,但它在交越附近就開始吃相位 —— 截止頻率不夠高時,比不濾還糟。
- **機構**:降低慣量比(加大馬達側慣量、改傳動比)直接把抬升量 $(1+J_l/J_m)$ 砍掉。

## 實驗設計

| 項目 | 設定 |
|---|---|
| 機台 | $J_m = 2\times10^{-4}$、$J_l = 1.8\times10^{-3}$(慣量比 9)、$k_s = 100$ Nm/rad、$c_s = 0.005$ |
| 控制 | 2 kHz 速度迴路 `DiscretePID(kp, ki=5)` + 一拍計算延遲 `Delay(1)`,回授馬達端速度 $\omega_m$ |
| 穩定判據 | 2 s 模擬不發散,且最後 20% 的峰對峰殘留振盪 < 0.05 |
| $k_p$ 掃描 | 0.05~1.00(步距 0.05)再 1.1~4.0(步距 0.1),第一次失敗即停 |

### 實驗 1:Bode 圖與增益抬升

以解析轉移函數畫 two-mass 與剛體($J_m+J_l$)的 Bode 圖,並在 400 Hz 讀取兩者增益差。

### 實驗 2:增益上限掃描(同一把尺)

五種組態:剛體(同總慣量 $2\times10^{-3}$)、two-mass 無處置、+60 Hz 一階低通、+共振頻率 notch(Q=2,`scipy.signal.iirnotch`)、
慣量比 1:1 的機構($J_m = J_l = 10^{-3}$,總慣量相同)。

### 實驗 3:失穩頻率

以 $k_{p,max}+0.1$ 跑 two-mass 無處置,取最後 2048 點做 Hanning 窗 FFT,找振盪頻率並與 $k_p/(2\pi J_m)$ 比較。

## 結果

| 特徵 | 數值 |
|---|---:|
| 反共振 | 37.5 Hz |
| 共振 | 118.6 Hz |
| 400 Hz 增益抬升 | 20.7 dB(理論 20.0 dB) |

| 組態 | $k_{p,max}$ |
|---|---:|
| rigid body (dream) | 3.90 |
| two-mass, no cure | 0.30 |
| two-mass + LPF 60 Hz | 0.10 |
| two-mass + notch @res | 0.35 |
| two-mass, Jl/Jm=1 (mech!) | 1.90 |

| 失穩分析($k_p = 0.40$) | 數值 |
|---|---:|
| 量測振盪頻率 | 348 Hz |
| 第二交越預測 $k_p/(2\pi J_m)$ | 318 Hz |
| 共振頻率 | 119 Hz |

- **共振/反共振比** $118.6/37.5 = 3.16 = \sqrt{10}$,正好是 $\sqrt{1+J_l/J_m}$。
- **抬升 20.7 dB 略大於 20 dB**:400 Hz 只在共振之上約 3.4 倍,尚未完全進入 $1/(J_m s)$ 漸近線。
- **共振把可用增益砍 13 倍**(3.90 → 0.30):慣量比帶來的 10 倍,加上共振峰附近增益比漸近線更高。
- **振盪在 348 Hz,不是 119 Hz 共振頻率**:失穩發生在第二交越,那裡的相位被一拍延遲吃掉;
  量測略高於 318 Hz 的預測,也是因為此頻段增益比 $1/(J_m\omega)$ 還大一點,交越被推得更高。
- **Notch 只小補**(0.30 → 0.35):峰被挖掉,但第二交越依然存在。
- **LPF 60 Hz 反而更差**(0.10):60 Hz 截止太低,在交越附近疊了大量相位落後。
- **慣量比 1:1 拉回 6 倍以上**(1.90):$J_m$ 從總慣量的 1/10 變成 1/2,$k_{p,max} \approx 3.90/2$ —— 與剛體上限的比例完全吻合。

## ✅ 驗證條件

| 條件 | 意義 |
|---|---|
| $|\text{lift} - 20\log_{10}(1+J_l/J_m)| < 2$ dB | 共振之上增益抬升 = 慣量比 |
| 剛體 $k_{p,max} > 3$ | 延遲限制下的「理想」基準 |
| two-mass $k_{p,max} \le$ 剛體 / 5 | 共振砍增益 ≥ 5 倍 |
| notch $k_{p,max} \ge$ 無處置 | notch 至少不會變差 |
| LPF $k_{p,max} \le$ 無處置 | 低通在此機台失敗 |
| 慣量比 1:1 $k_{p,max} \ge 4\times$ 無處置 | 機構改善最有效 |
| $|f_{osc} - f_{pred}|/f_{pred} < 35\%$ | 振盪頻率 ≈ 第二交越 $k_p/(2\pi J_m)$ |

## 工程意義與常見誤區

- **每台機器的數字不同,機制永遠相同**:共振讓馬達在高頻只看到 $J_m$,可用增益大約按 $J_m/(J_m+J_l)$ 縮小。
- **「共振在 119 Hz,所以我在 119 Hz 放 notch 就好」是常見誤區**:失穩在 348 Hz,notch 在那裡只剩些微影響(本例只把上限從 0.30 推到 0.35)。
  Notch 適合「共振峰本身」造成的問題(例如慣量比小、峰很尖時),不適合對付高頻增益抬升。
- **濾波器不是萬靈丹**:低通截止頻率要遠高於交越,否則它吃的相位比它壓的增益更要命。
- **Ellis 的名言:最好的控制器修不好爛機構**。提高 $k_s$(剛性聯軸器、縮短軸長)、降低慣量比(減速比、加大馬達)通常比任何濾波器都有效。
  但剛性提高會把共振推到更高頻,最後撞上取樣延遲(練習 2)。
- **Collocated vs non-collocated**:本章回授在馬達端(感測器與致動器同位置),相位行為最好;
  改用負載端回授,共振以上會多出 180° 相位,幾乎不能控(練習 3)。工業界的雙編碼器架構就是為此而生(練習 4)。
