## 一句話重點

編碼器量的是「位置」,速度要靠差分算出來 —— 差分把量化階 $q$ 放大成 $q/T_s$ 等級的速度雜訊,
而這份雜訊會直接限制速度迴路能用的增益。

## 學習目標

1. 理解編碼器**解析度 → 速度雜訊**的放大機制:差分把量化階 $q$ 放大成 $q/T_s$。
2. 驗證理論公式:速度雜訊 RMS $\approx \dfrac{q}{\sqrt{6}\,T_s}$($q$ = 量化階 [rad])。
3. 認識補救手段的取捨:移動平均(降雜訊、加延遲)。
4. 為第 18 章鋪路:觀測器才是「降雜訊又不加延遲」的根本解法。

## 理論重點

### 量化:位置只能是 $q$ 的整數倍

增量式編碼器 $N_{lines}$ 線,經四倍頻(quadrature)後每轉 $4N_{lines}$ counts,量化階

$$q = \frac{2\pi}{4N_{lines}}\ \text{[rad]}$$

本教材的 `EncoderModel` 以 `floor` 取整:$\theta_q = q\lfloor \theta / q \rfloor$,
量化誤差 $\varepsilon = \theta - \theta_q \in [0, q)$。只要運動夠「不規則」,$\varepsilon$ 可視為均勻分布,變異數 $q^2/12$。

### 差分速度雜訊公式

固定時間法(每 $T_s$ 取一次位置差):

$$\hat\omega_k = \frac{\theta_{q,k} - \theta_{q,k-1}}{T_s} = \omega_k + \frac{\varepsilon_{k-1} - \varepsilon_k}{T_s}$$

兩個相鄰的量化誤差近似獨立,相減後變異數加倍:$2 \cdot q^2/12 = q^2/6$,所以

$$\sigma_{\hat\omega} \approx \frac{q}{\sqrt{6}\,T_s}$$

關鍵在分母的 $T_s$:**取樣越快、雜訊越大**;解析度提高 $M$ 倍($q$ 縮小 $M$ 倍),雜訊就降 $M$ 倍。

### 移動平均(MA)的取捨

$N$ 點移動平均 $\bar\omega_k = \frac1N\sum_{j=0}^{N-1}\hat\omega_{k-j}$。對差分速度而言它會「伸縮相消」:

$$\bar\omega_k = \frac{\theta_{q,k} - \theta_{q,k-N}}{N\,T_s} \quad\Rightarrow\quad \sigma \approx \frac{q}{\sqrt6\,N T_s}$$

雜訊降 $N$ 倍(比白雜訊平均的 $\sqrt N$ 更好),但代價是群延遲

$$\tau_{MA} = \frac{N-1}{2}\,T_s$$

當速度在變化時,延遲會變成**追蹤誤差**:$e \approx \dot\omega \cdot \tau_{MA}$。延遲在迴路裡就是相位落後(第 4 章),同樣會吃掉相位邊限。

```
θ ──►[量化 q]──θq──►[差分 /Ts]──ω̂(雜訊 q/(√6·Ts))──►[MA N 點]──ω̄(雜訊 ÷N,延遲 (N−1)/2·Ts)
```

## 實驗設計

| 項目 | 設定 |
|---|---|
| 取樣 | $f_s = 1$ kHz($T_s = 1$ ms),2000 點(2 s) |
| 真實速度 | $\omega(t) = 1 + 0.5\sin(2\pi\cdot 3t)$ rad/s(變速,避免量化誤差週期化) |
| 位置 | $\theta = \sum \omega\,T_s$(以 rev 為單位餵給 `EncoderModel`) |
| 編碼器 | 500 / 2500 / 10000 線(×4 = 2000 / 10000 / 40000 counts/rev) |
| 誤差統計 | 捨去前 100 點暫態,計算 $\hat\omega - \omega$ 的標準差 |

### 實驗 1:解析度 vs 差分速度雜訊

三種線數各自量化位置、做一階差分,比較量測 RMS 與理論 $q/(\sqrt6 T_s)$。

### 實驗 2:移動平均的雜訊/延遲取捨

固定 2500 線,對差分速度做 $N = 1, 4, 16$ 點移動平均,記錄雜訊 RMS 與群延遲 $(N-1)/2 \cdot T_s$。

## 結果

| 線數 | counts/rev | 量測 RMS [rad/s] | 理論 $q/(\sqrt6 T_s)$ |
|---:|---:|---:|---:|
| 500 | 2000 | 1.4130 | 1.2825 |
| 2500 | 10000 | 0.2465 | 0.2565 |
| 10000 | 40000 | 0.0659 | 0.0641 |

| 移動平均 | 雜訊 RMS [rad/s] | 群延遲 |
|---|---:|---:|
| MA1(不平均) | 0.2465 | 0.0 ms |
| MA4 | 0.0681 | 1.5 ms |
| MA16 | 0.0523 | 7.5 ms |

- **解析度 20 倍 → 雜訊約 21 倍**(1.4130 / 0.0659 ≈ 21.4),與 $q \propto 1/N_{lines}$ 一致。
- 500 線偏離理論約 10%:每個取樣點只移動約 $1\times10^{-3}$ rad,不到一個 $q$($3.1\times10^{-3}$ rad),
  count 只是偶爾跳一格,量化誤差不再像獨立的均勻分布 —— 低解析度/低速正是公式失準的地方。
- **MA4** 雜訊 0.0681,接近「伸縮相消」預測的 $0.2565/4 = 0.064$:平均幾乎全拿到 $1/N$ 的好處。
- **MA16** 雜訊只降到 0.0523,而不是 $0.2565/16 = 0.016$ —— 多出來的是**延遲造成的追蹤誤差**:
  $\dot\omega$ 的振幅 $0.5 \cdot 2\pi\cdot 3 \approx 9.4$ rad/s²,乘 7.5 ms 得誤差振幅 0.071,RMS ≈ 0.050。
  平均越長,量化雜訊越小,延遲誤差越大,兩者在 MA16 已經是延遲主導。

## ✅ 驗證條件

| 條件 | 意義 |
|---|---|
| 三種線數的量測 RMS 與理論相差 < 35% | $q/(\sqrt6 T_s)$ 公式正確描述差分雜訊 |
| RMS(500) > RMS(2500) > RMS(10000) | 解析度越高雜訊越小 |
| 10 < RMS(500)/RMS(10000) < 40 | 解析度 20 倍 → 雜訊約 20 倍 |
| MA16 雜訊 < MA1 雜訊 / 2 | 平均確實降雜訊 |
| MA16 群延遲 > 5 ms | 代價:延遲 |

## 工程意義與常見誤區

- **「取樣越快越好」在速度估測上不成立**:$T_s$ 在分母,把 1 kHz 改成 10 kHz,同一顆編碼器的差分雜訊變大 10 倍。
- **雜訊會被迴路增益放大成轉矩雜訊**:速度迴路輸出 $\approx k_p \cdot \sigma_{\hat\omega}$,
  造成馬達發熱與可聽見的嘶聲。這是實務上限制速度迴路 $k_p$ 的主因之一(第 18 章量化這件事)。
- **平均/低通不是免費的**:它們把雜訊換成相位落後。MA16 的 7.5 ms 延遲,放進 100 Hz 級的速度迴路幾乎等於直接不穩。
- **換高解析度編碼器**最直接但最貴;更聰明的做法是用**觀測器**(模型 + 轉矩命令預測速度),
  在不加相位落後的前提下濾掉量化雜訊 —— 第 18 章的主題。
- **1/T 法**(量測兩個 count 邊緣的時間間隔)在低速時比固定時間法精確得多,但高速時每個週期內有很多 count,又變回固定時間法較好;
  實務驅動器常兩者混用。
- **Resolver(解角器)**是類比感測器,解析度由 R/D 轉換決定;它的主要誤差是與角度相關的諧波誤差,
  在速度訊號裡表現為與轉速成正比的頻率成分(練習 3)。
