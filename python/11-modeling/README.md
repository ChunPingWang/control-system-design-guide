## 一句話重點

模型只要在「你要用的頻段」正確即可:DC 馬達的電感在電氣極點(~160 Hz)以下幾乎看不見,迴路頻寬遠低於此時可以放心降階;
而任何模型都要用**兩條獨立的實作路徑**交叉驗證,才敢說它寫對了。

## 學習目標

1. 從物理方程推導 DC 馬達完整模型(電氣 + 機械),並辨認電氣、機械兩個時間常數。
2. 學會**降階**:何時可以忽略電感?用 Bode 圖看出降階模型的有效頻段。
3. 用兩條獨立路徑(解析 TF vs 數值積分)交叉驗證模型 —— 建模工作的基本紀律。

## 理論重點

### 物理方程與方塊圖

$$L\frac{di}{dt} = V - Ri - K_e\omega, \qquad J\frac{d\omega}{dt} = K_t i - b\omega$$

```
V ──►(+)──► [1/(Ls+R)] ──i──► [K_t] ──T──► [1/(Js+b)] ──┬──► ω
     ▲-                                                  │
     └──────────────────── [K_e] ◄── 反電動勢 ◄───────────┘
```

反電動勢 $K_e\omega$ 形成一個**天生的速度回授**,把電氣與機械動態耦合在一起。

### 完整模型與降階模型

$$P_{full}(s) = \frac{\omega}{V} = \frac{K_t}{(Ls+R)(Js+b) + K_tK_e}$$

令 $L\to0$:

$$P_{red}(s) = \frac{K_t}{R(Js+b)+K_tK_e} = \frac{K_t/(Rb+K_tK_e)}{\tau_m s + 1}$$

兩個時間常數:

$$\tau_e = \frac{L}{R}, \qquad \tau_m = \frac{RJ}{Rb + K_tK_e}$$

兩者 DC 增益完全相同 $K_t/(Rb+K_tK_e)$ —— 電感只影響動態,不影響穩態。
當 $\tau_m \gg \tau_e$ 時,完整模型的兩極點接近 $-1/\tau_e$ 與 $-1/\tau_m$;但因反電動勢耦合,實際極點會被**互相拉近**
(特徵方程式 $LJs^2 + (Lb+RJ)s + (Rb+K_tK_e) = 0$ 的根不等於兩個時間常數的倒數)。

### 為什麼降階有效

在 $\omega \ll 1/\tau_e$ 時,$Ls + R \approx R$,電氣迴路幾乎是瞬時的(電流立刻跟上電壓)。
速度迴路頻寬若遠低於電氣極點,忽略電感造成的相位誤差可以忽略;
反之,若要設計電流迴路或高頻寬速度迴路,就必須保留電感(第 15 章)。

### 交叉驗證的紀律

同一組微分方程,用兩種完全獨立的方式實作:python-control 的解析步階響應(矩陣指數精確離散化),
與 `DCMotorPlant` 的 1 µs 前向 Euler 逐樣本積分。兩者吻合 → 方程式、符號、單位都沒寫錯。

計算 $\tau_e$、$\tau_m$、完整模型極點,疊圖比較兩模型,並在 1 Hz 與 1 kHz 比較增益差。

### 實驗 2:交叉驗證

1 V 步階下,逐樣本模擬與解析步階響應的最大相對誤差,以及 50 ms 時的轉速對照 DC 增益。

## 結果

| 項目 | 數值 |
|---|---:|
| 電氣時間常數 $\tau_e$ | 1.00 ms(極點 1000 rad/s ≈ 159 Hz) |
| 機械時間常數 $\tau_m$ | 9.99 ms(極點 100 rad/s ≈ 15.9 Hz) |
| 完整模型極點 | −887.28、−112.82 rad/s |
| 兩實作最大相對誤差 | 0.008% |
| 50 ms 時模擬轉速 | 9.949 rad/s |
| 解析 DC 增益 | 9.990 rad/s/V |
| 完整 − 降階增益差 @1 Hz | 0.003 dB |
| 完整 − 降階增益差 @1 kHz | −16.05 dB |

(1 Hz / 1 kHz 增益差由 C++ 版印出;notebook 在 assertion 中檢查同一量。本章無亂數,兩版一致。)

- $\tau_m/\tau_e \approx 10$,完整模型極點 −887 / −113 rad/s,與 $1/\tau_e=1000$、$1/\tau_m=100$ 相近但被反電動勢耦合互相拉近約 11~13%。
- 1 Hz 兩模型幾乎重合(差 0.003 dB);1 kHz 時完整模型多了一個約 141 Hz 的電氣極點,增益低 16 dB、相位多落後約 80° —— 降階模型在這裡已經失效。
- 1 µs Euler 與精確解只差 0.008%:步長比最快的時間常數(1/887 ≈ 1.13 ms)小三個數量級,Euler 截斷誤差很小。
- 50 ms 的 9.949 比 DC 增益 9.990 低 0.4%,不是模型錯,而是還沒完全穩定:主極點時間常數 8.86 ms,50 ms ≈ 5.6 個時間常數,殘餘項 $\frac{887.28}{774.47}e^{-5.64}\approx 0.4\%$。

## ✅ 驗證條件

| 條件 | 意義 |
|---|---|
| 解析 vs 逐樣本最大相對誤差 < 1% | 兩條獨立實作一致 → 模型寫對了 |
| 完整與降階 DC 增益相對差 < 1e-6 | 降階不改變穩態增益 |
| 1 Hz 增益差 < 0.1 dB | 低頻段降階模型有效 |
| 1 kHz 增益差 > 3 dB | 高於電氣極點後降階模型失效 |
| 50 ms 模擬轉速與 DC 增益相差 < 1% | 穩態值符合理論 |

## 工程意義與常見誤區

- **「模型越完整越好」是誤解**:模型的價值在於「在需要的頻段夠準且夠簡單」。低頻寬速度迴路用一階模型設計即可;硬把電感、摩擦、共振全部放進去,只會讓調機與理解變難。
- **降階的判斷準則是頻寬比**:被忽略的極點至少要比迴路交越頻率高 5~10 倍(與第 9 章濾波器相位法則同一件事)。
- **反電動勢是免費的阻尼**:$\tau_m$ 的分母 $Rb + K_tK_e$ 中,$K_tK_e = 0.01$ 遠大於 $Rb = 10^{-5}$ —— 電壓驅動馬達的「機械時間常數」幾乎完全由反電動勢決定,而非機械摩擦。改用電流驅動(第 15 章)後這個阻尼就消失了。
- **交叉驗證不能省**:符號錯一個($-K_e\omega$ 寫成 $+$)模型可能依舊「看起來合理」;兩條獨立路徑不一致時,至少有一條是錯的。
- **模擬步長要比最快動態小很多**:以 Euler 積分電氣動態時,$dt$ 必須遠小於 $\tau_e$;這也是本章選 1 µs 的原因。
