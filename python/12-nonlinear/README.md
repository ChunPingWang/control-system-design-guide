## 一句話重點

真實系統的飽和、摩擦、背隙都不是 LTI,Bode 圖看不到它們;只能逐樣本模擬。
三個經典症狀:**飽和 + 積分器 = windup 大超越**、**庫倫摩擦 = 速度過零的誤差尖峰**、**背隙 = 反轉時的失動與遲滯**。

## 學習目標

1. **飽和 + 積分器 = windup**:認識它、用條件積分(conditional integration)解決它(anti-windup)。
2. **庫倫摩擦**:理解零速附近的追蹤誤差尖峰從何而來。
3. **背隙(backlash)**:觀察反轉時的失動量與遲滯迴線。
4. 體會為什麼這一章「必須逐樣本模擬」—— 線性工具(轉移函數、Bode)無法描述這些行為。

## 理論重點

### 積分器 windup 與條件積分

```
e ──► [kp + ki∫] ──u_unsat──► [ 飽和 ±u_max ] ──u──► 受控體
            ▲                        │
            └──── 條件積分:u ≠ u_unsat 且 e·u_unsat > 0 → 凍結積分器
```

致動器飽和時,迴路實際上是**開迴路**:輸出卡在 $\pm u_{max}$,不管誤差多大都無法再加力。
但 naive 積分器仍持續累積 $\int e\,dt$,儲存了大量「用不到的」控制量。
等輸出終於到達目標,誤差反號,積分器必須先把多累積的量「吐回」—— 期間輸出仍被推過頭,造成大幅 overshoot 與長時間收斂。

**條件積分**(本庫 `DiscretePID` 的 anti-windup):當輸出飽和、且誤差方向會讓 $u_{unsat}$ 更深入飽和時($e\cdot u_{unsat}>0$),暫停積分。
其他常見做法:back-calculation(以 $(u - u_{unsat})/T_t$ 回拉積分器)、積分器上下限箝制。

### 庫倫摩擦

$$T_f = f_c\,\mathrm{sign}(\omega)$$

摩擦大小固定、方向永遠與速度相反。速度過零時,摩擦轉矩瞬間從 $+f_c$ 跳到 $-f_c$,**等效於在受控體輸入端注入 $2f_c$ 的階躍擾動**。
PI 迴路穩態時由積分器提供 $f_c$ 的補償;反向後積分器來不及重建,只能先由比例項承擔:
$e \approx 2f_c/K_p$ 是誤差尖峰的上界。這就是機台在換向時出現的「象限突波」(quadrant glitch)。

### 背隙

```
        load
         ▲      ╱ ╱
         │    ╱ ╱       ← 上升、下降走不同的路徑
         │  ╱ ╱            水平段 = 失動(motor 動、load 不動)
         └──────────► motor
```

總寬度 $w$ 的背隙:輸入與輸出的差被限制在 $\pm w/2$;只有當間隙被吃完,負載才被推動。
輸入反轉時,負載先靜止 $w$ 的行程 → 輸入/輸出平面上形成平行四邊形的遲滯迴線。
在位置閉迴路中(回授取負載端),背隙可引起極限循環(limit cycle)。

## 實驗設計

| 項目 | 設定 |
|---|---|
| 受控體 | `MotorPlant`:$J=0.002$、$b=0.01$,$f_s = 1$ kHz、1.5 s |
| 實驗 1 | 速度步階 5 rad/s;`DiscretePID(kp=0.5, ki=20)`,輸出飽和 ±0.3 N·m;比較 `anti_windup=False/True` |
| 實驗 2 | 速度命令 $0.5\sin(2\pi\cdot1\,t)$;`DiscretePID(kp=0.5, ki=5)`;庫倫摩擦 $f_c = 0$ 與 0.05 N·m |
| 實驗 3 | `Backlash(width=0.02)`;馬達位置 $0.05\sin(2\pi\cdot0.5\,t)$ rad |

### 實驗 1:積分器 windup

大步階讓轉矩長時間卡在 +0.3 N·m,比較 naive 積分器與條件積分的速度 overshoot。

### 實驗 2:庫倫摩擦的零速死區

0.3 s 後(避開起始暫態)比較有無摩擦時的最大追蹤誤差,並檢查誤差尖峰是否位於速度命令過零點附近(±0.15 s 內)。

### 實驗 3:背隙

開環推動背隙元件,量測馬達與負載位置差(失動量)的範圍。

## 結果

| 實驗 | 指標 | 結果 |
|---|---|---:|
| 1 windup | overshoot(naive 積分器) | 2.428 rad/s(48.6%) |
| 1 windup | overshoot(anti-windup) | 0.002 rad/s |
| 2 摩擦 | 最大追蹤誤差(無摩擦) | 0.0086 rad/s |
| 2 摩擦 | 最大追蹤誤差($f_c = 0.05$) | 0.1604 rad/s |
| 3 背隙 | 失動量範圍 | $[-0.0100,\ 0.0100]$ rad(理論 ±0.01) |

- **windup**:naive 積分器的 overshoot 是 anti-windup 的上千倍。以 0.3 N·m 加速,約 37 ms 就到達 5 rad/s,但這段期間積分器已累積 $k_i\int e\,dt \approx 20\times0.091 \approx 1.8$ N·m,而穩態只需要 $b\omega = 0.05$ N·m;多出來的量只能靠負誤差慢慢吐掉,轉矩一直卡在 +0.3 N·m 到 55 ms,速度在 58 ms 衝到 7.43 rad/s(以上時間點取自 `ch12_windup.csv`)。條件積分在飽和期間凍結積分器,幾乎沒有 overshoot。
- **摩擦**:誤差放大 18.7 倍。摩擦反向等於 $2f_c = 0.1$ N·m 的階躍擾動,比例項需 $e = 0.1/0.5 = 0.2$ rad/s 才能即時扛住;實際 0.16 rad/s 略低,因為受控體慣量與積分器也分擔了一部分。尖峰位置落在速度過零點附近,驗證了「換向突波」的機制。
- **背隙**:失動量精確為 ±0.01 rad(總寬 0.02 rad 的一半),負載在每次反轉時靜止,直到馬達走完 0.02 rad 的間隙。

## ✅ 驗證條件

| 條件 | 意義 |
|---|---|
| naive overshoot > 2 × max(anti-windup overshoot, 0.05) | windup 顯著惡化 overshoot |
| anti-windup overshoot < 0.5 rad/s | 條件積分有效 |
| naive 情況 $\lvert u\rvert \le u_{max}$ | 飽和確實生效(模擬的是真飽和) |
| 有摩擦最大誤差 > 3 × 無摩擦 | 摩擦造成明顯誤差尖峰 |
| 誤差尖峰距最近的速度過零點 < 0.15 s | 尖峰發生在換向處 |
| 失動量最大 / 最小值與 ±0.01 相差 < 1e-3 | 背隙寬度正確 |

## 工程意義與常見誤區

- **每個有積分器、會飽和的控制器都需要 anti-windup**:包括速度迴路、溫度控制、電流迴路。沒做 anti-windup 的迴路,小步階測試完全正常,大步階才露餡 —— 只做小訊號測試是常見的驗證漏洞。
- **飽和讓線性設計失效**:所有第 2~3 章的邊限分析都假設迴路是線性的;飽和期間迴路增益實際上下降,大訊號響應要另外驗證。
- **摩擦補償不等於加大增益**:加大 $K_p$ 能縮小尖峰,但受限於穩定性;常見做法是依速度方向前饋 $f_c\,\mathrm{sign}(\omega_{ref})$(練習 2),但低速時方向判斷與靜摩擦(stiction)仍是難題。
- **背隙不能靠控制器「調掉」**:它是機構問題。把回授取在負載端會引入極限循環;取在馬達端則負載位置有 ±w/2 的不確定性。實務上常用預壓齒輪、雙馬達反向預載或背隙補償。
- **時變性**:慣量隨姿態變化(機械手臂)也會讓固定增益在某些位置過激、某些位置過軟(練習 4)。
