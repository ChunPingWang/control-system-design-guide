## 一句話重點

回授用「量測 + 修正」取代「事先算準」:只要迴路增益夠大,輸出就幾乎不受受控體參數漂移與外部擾動影響。

## 學習目標

1. 分辨**開迴路**(open-loop)與**閉迴路**(closed-loop)控制的結構差異。
2. 用數值實驗看見回授如何降低系統對**受控體參數變化**的敏感度。
3. 用數值實驗看見回授(特別是積分作用)如何**消除外部擾動**造成的穩態誤差。
4. 了解回授的代價:需要感測器、增益過高會不穩定(第 2、3 章的主題)。

## 理論重點

### 開迴路 vs 閉迴路

```
開迴路:  r ──► [1/K_nom] ──u──► [P(s)] ──► y           (不看 y,憑模型算 u)

閉迴路:  r ──►(+)──e──► [C(s)] ──u──► [P(s)] ──┬──► y
              ▲-                                 │
              └──────────────── 量測 ────────────┘
```

閉迴路轉移函數:

$$T(s) = \frac{Y(s)}{R(s)} = \frac{C(s)P(s)}{1 + C(s)P(s)}$$

當迴路增益 $|C P| \gg 1$ 時,$T \approx 1$ —— 輸出追得上命令,**與 $P$ 的確切數值無關**。這是回授的核心價值。

### 靈敏度函數

衡量「受控體變化多少,閉迴路跟著變多少」的指標是靈敏度函數:

$$S(s) = \frac{1}{1 + C(s)P(s)}, \qquad \frac{dT/T}{dP/P} = S$$

開迴路的靈敏度恆為 1(受控體增益錯 50%,輸出就錯 50%);閉迴路在 $|CP|$ 大的頻段,$|S| \ll 1$。
PI 控制器在 $s \to 0$ 時 $|C| \to \infty$,所以**直流(穩態)的 $S = 0$**:穩態誤差完全消失。

### 擾動抑制

擾動 $d$ 從受控體輸入端進入時,到輸出的轉移函數為:

$$\frac{Y(s)}{D(s)} = \frac{P(s)}{1 + C(s)P(s)} = P(s)\,S(s)$$

同樣被 $S$ 壓低;積分器讓低頻擾動的穩態影響歸零。

## 實驗設計

| 項目 | 設定 |
|---|---|
| 受控體 | 一階系統 $P(s) = \dfrac{K}{0.1s + 1}$(如驅動器電壓 → 速度),標稱 $K_{nom}=2$ |
| 開迴路控制 | 以標稱模型反算:$u = r / K_{nom} = 0.5$ |
| 閉迴路控制 | PI:$C(s) = 2 + 20/s$ |
| 模擬時間 | 0 ~ 1.5 s,1500 點(`control.forced_response` / `step_response`) |

### 實驗 1:受控體增益漂移 ±50%

實際增益 $K \in \{1, 2, 3\}$。開迴路以固定的 $u=0.5$ 驅動;閉迴路以 PI 追單位步階。
觀察兩者的最終穩態誤差。

### 實驗 2:擾動抑制

$K = K_{nom}$,在 $t = 0.75$ s 於受控體輸入端注入 $-0.5$ 的階躍擾動(例如負載突增)。
閉迴路響應以**線性疊加**計算:命令響應 $T \cdot r$ 加上擾動響應 $\frac{P}{1+CP} \cdot d$。

## 結果

| $K$ | 開迴路穩態誤差 | 閉迴路穩態誤差 |
|---:|---:|---:|
| 1.0 | 0.5000 | 0.000000 |
| 2.0 | 0.0000 | 0.000000 |
| 3.0 | −0.5000 | 0.000000 |

| 擾動實驗 | 最終誤差 |
|---|---:|
| 開迴路 | 0.9994 |
| 閉迴路(PI) | 0.000184 |

- 開迴路只有在模型「剛好正確」($K=2$)時才準;增益錯 50%,輸出就錯 50%。
- 閉迴路對三種增益都收斂到 0 誤差 —— 積分器持續累積誤差直到誤差為零。
- 擾動讓開迴路輸出幾乎歸零(誤差 ≈ 1.0);閉迴路在擾動後短暫偏離,隨即被積分器拉回。

## ✅ 驗證條件

| 條件 | 意義 |
|---|---|
| $K=2$ 時開迴路誤差 < 1e-3 | 模型正確時,開迴路也能準 |
| $K=1$ 時開迴路誤差 ≈ 0.5(±0.01) | 模型錯 50% → 輸出錯 50% |
| 三種 $K$ 的閉迴路誤差皆 < 1e-3 | 回授對參數變化不敏感 |
| 擾動後開迴路誤差 > 0.2 | 開迴路無法反應擾動 |
| 擾動後閉迴路誤差 < 1e-3 | 積分作用消除擾動穩態誤差 |

## 工程意義與常見誤區

- **「模型夠準就不需要回授」是誤解**:真實受控體的增益會隨溫度、負載、老化漂移,擾動更無法事先預知。
- **回授不是免費的**:它需要感測器(成本、雜訊、延遲),而且增益越高越可能不穩定。
  如何在「增益夠高」與「保持穩定」之間取捨,就是第 2 章(頻域、邊限)與第 3 章(調機)的主題。
- **積分器的角色**:純 P 控制只能讓誤差變小、不能變零;要消除穩態誤差需要積分作用(練習 1)。
