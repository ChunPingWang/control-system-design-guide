## 一句話重點

伺服驅動器是一組串級迴路:最內層的**電流迴路**用 PI 零點對消電氣極點、把「電壓→電流」變成快又乾淨的一階系統,
外層速度迴路只要把它當成「理想轉矩源」來設計 —— 前提是兩者頻寬拉得夠開。

## 學習目標

1. 設計**電流迴路**:PI 零點對消電氣極點($k_p = L\omega_c$、$k_i = R\omega_c$)。
2. 理解串級頻寬分離法則:電流迴路頻寬 ≈ 速度迴路的 10 倍。
3. 看見電壓飽和與電流極限如何限制動態(轉矩受限的加速)。
4. 認識**反電動勢**:穩態電壓 = $K_e\omega + Ri$,轉速越高,留給電流控制的電壓餘裕越少。

## 理論重點

### 直流馬達模型

$$L\frac{di}{dt} = V - Ri - K_e\omega, \qquad J\frac{d\omega}{dt} = K_t i - b\omega - T_L$$

電氣時間常數 $L/R = 1$ ms(電氣極點 $R/L = 1000$ rad/s ≈ 159 Hz);$K_e\omega$ 是反電動勢,
對電流迴路而言是一個**隨轉速緩慢變化的擾動**。

```
             ┌──── 速度迴路 PI ────┐   ┌──── 電流迴路 PI ────┐
ω_ref ──►(+)─► kp_v + ki_v/s ─►[clip ±5 A]─►(+)─► kp_i + ki_i/s ─►[clip ±24 V]─► 1/(Ls+R) ─i─► Kt ─► 1/(Js+b) ─┬─► ω
          ▲-                          i_cmd  ▲-                              ▲-(Ke·ω 反電動勢)              │
          │                                  └──────────── i ────────────────┘                              │
          └─────────────────────────────────────────── ω ───────────────────────────────────────────────────┘
```

### 電流迴路:極點—零點對消

PI 控制器 $C_i(s) = k_p + k_i/s = k_p\dfrac{s + k_i/k_p}{s}$。令零點 $k_i/k_p = R/L$ 對消電氣極點:

$$C_i(s)\,\frac{1}{Ls+R} = \frac{L\omega_c\,(s+R/L)}{s}\cdot\frac{1}{L(s+R/L)} = \frac{\omega_c}{s}
\quad\Rightarrow\quad \frac{I}{I_{cmd}} = \frac{\omega_c}{s+\omega_c}$$

閉迴路是頻寬 $\omega_c$ 的**一階系統**,10–90% 上升時間 $t_r = 2.2/\omega_c = 0.35/f_{BW}$。
所以 $k_p = L\omega_c$、$k_i = R\omega_c$:電感決定比例、電阻決定積分。

### 速度迴路與頻寬分離

電流迴路夠快時,$i \approx i_{cmd}$,速度受控體就是 $K_t/(Js)$。取 $k_{p,v} = J\omega_{c,v}/K_t$
得交越頻率 $\omega_{c,v}$;積分零點放在交越的 1/10(8 Hz),幾乎不吃相位。
內環頻寬 800 Hz、外環 80 Hz,**比例 10:1** —— 內環在外環交越處只貢獻約 $\arctan(0.1) \approx 6°$ 相位落後,
外環可以把它當成理想轉矩源。

### 飽和:電流極限 = 轉矩極限

速度 PI 的輸出被夾在 ±5 A,大步階時速度迴路飽和,馬達以最大轉矩等加速:

$$\alpha_{max} = \frac{K_t I_{max}}{J} = \frac{0.1 \times 5}{10^{-4}} = 5000\ \text{rad/s}^2$$

100 rad/s 大約需要 20 ms。穩態時 $i = b\omega/K_t$,電壓 $V = K_e\omega + Ri$。

## 實驗設計

| 項目 | 設定 |
|---|---|
| 馬達 | $R=1\,\Omega$、$L=1$ mH、$K_t=K_e=0.1$、$J=10^{-4}$ kg·m²、$b=10^{-5}$ |
| 模擬 | `DCMotorPlant` + `DiscretePID`,步長 $dt = 1\ \mu$s |
| 電流迴路 | 目標頻寬 800 Hz:$k_p = L\omega_c = 5.027$、$k_i = R\omega_c = 5027$;電壓極限 ±24 V |
| 速度迴路 | 交越 80 Hz:$k_p = J\omega_{c,v}/K_t = 0.5027$、$k_i = k_p\cdot 2\pi\cdot 8 = 25.266$;電流極限 ±5 A |

### 實驗 1:電流迴路步階

轉子自由(會轉,有反電動勢),命令 1 A 電流步階,模擬 5 ms,量測 10–90% 上升時間與穩態電流。

### 實驗 2:串級速度迴路大步階

速度命令 100 rad/s,模擬 200 ms。記錄轉速、電流、電壓,觀察電流受限的等加速段與穩態電壓。

## 結果

| 電流迴路 | 數值 |
|---|---:|
| $k_p$ / $k_i$ | 5.027 / 5027 |
| PI 零點 $k_i/k_p$ | 1000 rad/s(= 電氣極點 $R/L$) |
| 10–90% 上升時間 | 442 µs |
| 理論 $0.35/\text{BW}$ | 437 µs |

| 速度迴路 | 數值 |
|---|---:|
| $k_p$ / $k_i$ | 0.5027 / 25.266 |
| 最終轉速 | 100.00 rad/s |
| 穩態電壓 | 10.01 V(理論 $K_e\omega + Ri$ = 10.01 V) |
| 峰值電流 | 4.92 A(極限 5 A) |
| 轉速 overshoot | 0.65 rad/s |

- **上升時間 442 µs vs 理論 437 µs**:對消設計讓電流迴路精確成為一階系統;1% 的差距來自 1 µs 離散化與反電動勢擾動。
- **穩態電壓 10.01 V** = 反電動勢 $0.1\times100 = 10$ V + 電阻壓降 $1\times0.01$ A(摩擦所需電流)。
  電壓幾乎全部花在反電動勢上 —— 這就是高速時電壓不夠用的原因。
- **峰值電流 4.92 A 而非 5 A**:加速期間反電動勢以 $K_e\alpha = 500$ V/s 斜坡上升,對電流 PI 而言是斜坡擾動,
  型 1 迴路追斜坡擾動會留下約 $500/k_i \approx 0.1$ A 的定值誤差。
- **overshoot 僅 0.65 rad/s**:`DiscretePID` 的條件積分(anti-windup)在電流受限期間凍結積分器,離開飽和時不會暴衝。

## ✅ 驗證條件

| 條件 | 意義 |
|---|---|
| 上升時間與 0.35/800 Hz 相差 < 40% | 電流迴路頻寬達標(對消設計有效) |
| 最終電流與 1 A 相差 < 0.05 A | 電流迴路無穩態誤差 |
| 峰值電流 ≤ 5 A | 電流極限被尊重 |
| 最終轉速與 100 rad/s 相差 < 0.5 | 速度迴路到位 |
| 穩態電壓與 $K_e\omega + Ri$ 相差 < 0.5 V | 穩態電壓 = 反電動勢 + IR |
| 電流 > 4.5 A 的時間 > 10 ms | 確實出現轉矩受限的等加速段 |

## 工程意義與常見誤區

- **電流迴路的增益直接由電機參數算出**:$k_p = L\omega_c$、$k_i = R\omega_c$。驅動器的「自動調機」多半就是先量 $R$、$L$ 再套這兩條。
- **$R$、$L$ 會漂**:銅線溫升讓 $R$ 增加 30~40%,鐵芯飽和讓 $L$ 在大電流時下降。零點不再完美對消,
  但因為 PI 在交越附近主要靠 $k_p$,電流迴路通常只輕微變形 —— 對消設計對參數誤差不算敏感。
- **$K_t$ 誤差不影響電流迴路**:電流迴路只看得到電氣部分;$K_t$ 誤差會直接變成速度迴路的增益誤差(練習 4)。
- **頻寬分離不足**:若內環只比外環快 2 倍,內環相位落後會吃掉外環的相位邊限,出現振鈴甚至不穩(練習 1)。
- **反電動勢吃電壓餘裕**:電源電壓 $V_{bus}$ 必須大於 $K_e\omega_{max} + RI_{max}$ 加上動態所需,否則高速段電流迴路飽和、
  轉矩下降。常見誤區是只看額定轉矩不看額定轉速下的電壓。
- **大步階的梯形速度**是伺服機的正常波形:速度迴路飽和 → 最大電流 → 等加速。它不是「調機不好」,而是物理極限。
