## 一句話重點

建模不是閉門推導,而是「**量測 → 擬合 → 疊圖比對 → 找出不合處**」的循環;
**模型與量測不合的地方,就是還沒建進模型的物理** —— 本章在剛體模型解釋不了的 50~75 Hz 找到了機構柔性的共振/反共振。

## 學習目標

走一遍書中的建模驗證流程:

1. 對「未知的真實受控體」做 DSA(動態訊號分析儀)頻率響應量測,並用 coherence 判斷哪些頻率點可信。
2. 從低頻段擬合**剛體模型**(總慣量 $J_{tot}$)。
3. 疊圖比較:剛體模型在哪個頻段失效?失效處透露什麼物理?
4. 自動從量測資料找出共振峰與反共振谷,對照 two-mass 理論公式。

這裡的「真實受控體」用 two-mass 模型 + 量測雜訊扮演(參數假裝未知),實機版流程見 `hardware/` 與第 19 章。

## 理論重點

### DSA 量測:Welch 交叉頻譜

```
chirp u(t) ──► [ 未知受控體 ] ──► ω_m ──(+)──► y(t) = ω_m + 量測雜訊
     │                                           │
     └──────────────► [ Welch: P_uu, P_uy, 相干 ] ◄┘ ──► Ĥ(f) = P_uy / P_uu
```

$$\hat H(f) = \frac{P_{uy}(f)}{P_{uu}(f)}, \qquad
\gamma^2(f) = \frac{|P_{uy}(f)|^2}{P_{uu}(f)\,P_{yy}(f)} \in [0, 1]$$

交叉頻譜估計($H_1$ 估計)對**輸出端的不相關雜訊不偏**:雜訊與 $u$ 無關,平均後從 $P_{uy}$ 消失。
**Coherence** $\gamma^2$ 衡量 $y$ 中有多少比例能由 $u$ 線性解釋;$\gamma^2$ 低代表該頻率訊噪比差、非線性或非穩態,估測不可信。本章只保留 $\gamma^2 > 0.9$ 的點。

### 剛體模型與慣量擬合

剛體(轉矩 → 速度):$P(s) = \dfrac{1}{J_{tot}s}$,$\ |H(j\omega)| = \dfrac{1}{J_{tot}\,\omega}$。
在遠低於任何共振的 2~10 Hz 取每一點 $J_i = 1/(|H_i|\,\omega_i)$ 再平均。

### Two-mass(柔性耦合)模型

馬達 $J_m$ 與負載 $J_l$ 以剛性 $k_s$、阻尼 $c_s$ 的軸耦合,量測馬達速度:

$$\frac{\omega_m}{T}(s) = \frac{J_l s^2 + c_s s + k_s}{s\,\big[J_mJ_l s^2 + (J_m+J_l)c_s s + (J_m+J_l)k_s\big]}$$

- **反共振**(分子零點,負載像動態吸振器把馬達「定住」):$\omega_{ar} = \sqrt{k_s/J_l}$
- **共振**(分母極點,兩慣量反相振動):$\omega_r = \sqrt{k_s\,\dfrac{J_m+J_l}{J_mJ_l}}$
- 低頻 $s\to0$:$\omega_m/T \to 1/[(J_m+J_l)s]$ —— 就是剛體模型,所以低頻擬合得到的是**總慣量**。
- 高頻:$\omega_m/T \to 1/(J_m s)$ —— 只剩馬達慣量,曲線比低頻高 $20\log_{10}(J_{tot}/J_m) = 6$ dB。

本例 $J_m = J_l = 10^{-3}$、$k_s = 100$:$f_{ar} = 50.3$ Hz、$f_r = 71.2$ Hz,阻尼比 $\zeta = c_s\,\omega_r/(2k_s) \approx 0.022$,是很尖的峰。

## 實驗設計

| 項目 | 設定 |
|---|---|
| 「未知」受控體 | `TwoMassPlant(Jm=1e-3, Jl=1e-3, ks=100, cs=0.01)`,$f_s = 10$ kHz |
| 激發 | 對數 chirp 2 → 300 Hz、20 s、振幅 0.5 N·m(`chirp_excitation`) |
| 量測雜訊 | 馬達速度加 $\sigma = 0.02$ rad/s 高斯雜訊(`default_rng(7)`) |
| FRF 估計 | `measure_frf`:Welch,Hann 窗、50% 重疊,`nperseg = min(N/8, 4096) = 4096` → $\Delta f = 2.44$ Hz |
| 有效點 | $\gamma^2 > 0.9$ 且 1.5 < f < 300 Hz |
| 擬合頻段 | 2~10 Hz;共振/反共振搜尋 30~150 Hz |

### 步驟 1:DSA 量測

以 chirp 激發「未知」受控體,估計馬達速度 / 轉矩的 FRF 與 coherence,篩出有效點。

### 步驟 2:低頻擬合剛體模型

從 2~10 Hz 的有效點反推 $J_{tot}$,建立 $P_{rigid} = 1/(J_{est}s)$;另以真值建 two-mass 解析模型作「事後」對照。

### 步驟 3:讀圖

在 30~150 Hz 找量測的最大(共振)與最小(反共振),對照理論,並計算共振處剛體模型的誤差。

## 結果

| 項目 | 量測 / 擬合 | 理論 / 真值 |
|---|---:|---:|
| 有效量測點 | 111 點,2.4 ~ 288.1 Hz | — |
| $J_{tot}$ | 2.000 mkg·m²(誤差 0.0%) | 2.000 mkg·m² |
| 共振頻率 | 75.7 Hz | 71.2 Hz(差 6.3%) |
| 反共振頻率 | 46.4 Hz | 50.3 Hz(差 7.8%) |
| 共振處量測 − 剛體模型 | 19.8 dB | — |

讀圖:

- **2~30 Hz**:剛體模型與量測重合 → 總慣量正確。
- **50 Hz 附近**:量測掉出一個谷(反共振)→ 剛體模型解釋不了。
- **70 Hz 附近**:量測衝出一個比剛體高約 20 dB 的峰(共振)→ 這是**機構柔性**的簽名(第 16 章主角)。

為什麼共振 / 反共振頻率差了 6~8%?這不是模型錯,而是**量測本身的限制**:

- 頻率解析度 $\Delta f = 10000/4096 = 2.44$ Hz,量測只能落在 2.44 Hz 的整數倍上(75.7 = 31Δf、46.4 = 19Δf)。
- 更關鍵的是 **coherence 篩選把極值附近的點刪掉了**(C++ 版 CSV 顯示 48.8~53.7 Hz 與 65.9~73.2 Hz 沒有有效點):
  反共振處馬達幾乎不動,輸出訊號淹沒在雜訊裡;共振處 $\zeta \approx 0.022$ 的尖峰在 chirp 掃過後持續振鈴,訊號非穩態。兩者都讓 $\gamma^2 < 0.9$。
  程式找到的是「缺口邊緣」的點,自然偏離真正的極值。
- 慣量擬合 0.0% 誤差部分是幸運:C++ 版資料中 2~10 Hz 的個別點相對剛體模型偏差達 −1.9 ~ +1.4 dB(最低頻點靠近 chirp 起始頻率 2 Hz,估計較差),平均後正好抵消。

## ✅ 驗證條件

| 條件 | 意義 |
|---|---|
| $\lvert J_{est} - J_{tot}\rvert / J_{tot} < 15\%$ | 低頻擬合出正確的總慣量 |
| 量測共振與理論相差 < 10% | DSA 找得到共振 |
| 量測反共振與理論相差 < 10% | DSA 找得到反共振 |
| 共振處量測 − 剛體模型 > 10 dB | 剛體模型在共振處明顯失效 |
| 2~10 Hz two-mass 模型與量測差 < 2 dB | 正確的模型在可信頻段與量測吻合 |

## 工程意義與常見誤區

- **書中的鐵律:模型與量測不合的地方,就是還沒建進模型的物理。** 不要把不合的部分當成「量測雜訊」忽略,也不要急著加一堆參數硬擬合。
- **不看 coherence 就讀 Bode 是常見錯誤**:低 coherence 的點可能是雜訊、非線性(摩擦、背隙)或共振振鈴造成的假象。本章也示範了反面:coherence 篩選太嚴會剛好刪掉你最想看的共振峰 —— 需要時應提高激發能量、放慢 chirp、增加平均次數或拉長 `nperseg`。
- **低頻擬合的是總慣量**:在共振以下,馬達與負載一起動;想分辨 $J_m$、$J_l$ 必須看共振以上的頻段(高頻漸近線 $1/(J_m s)$)或做完整擬合(練習 4)。
- **激發振幅的取捨**:振幅太小 → 訊噪比差;太大 → 飽和或非線性,線性 FRF 失去意義(練習 2)。
- **量測點選擇**:量馬達端(collocated)會看到先反共振後共振;量負載端(non-collocated)只有共振峰、沒有反共振谷,相位額外落後 180°,更難控制(練習 3,第 16 章)。
