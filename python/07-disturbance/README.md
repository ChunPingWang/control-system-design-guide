## 一句話重點

擾動響應是一條頻率曲線 $G_d = P/(1+CP)$:積分增益 $k_i$ 決定**低頻**抑制(每加 10 倍多 20 dB),比例增益 $k_p$ 決定**中頻**峰值,而回授在頻寬以上完全幫不上忙 —— 能量得到擾動時,直接前饋抵銷(擾動解耦)比等誤差累積有效得多。

## 學習目標

1. 建立「擾動響應是頻域函數」的觀念:$G_d = P/(1+CP)$。
2. 理解積分增益 $k_i$ 決定**低頻**擾動抑制,迴路頻寬(比例增益)決定**中頻**。
3. 實作**擾動解耦(disturbance decoupling)**:量測/估測擾動並前饋補償。
4. 看見量測延遲與增益誤差如何限制解耦的效果。

## 理論重點

### 擾動到輸出的轉移函數

```
                      T_L(負載轉矩)
                          │ −
 r=0 ─►(+)─e─► [C(s)] ─u─►(+)─► [P(s)=1/(Js+b)] ─┬─► ω
       ▲-                                        │
       └─────────────────────────────────────────┘
```

擾動從受控體輸入端進入時:

$$G_d(s) = \frac{\Omega(s)}{T_d(s)} = \frac{P}{1+CP}$$

代入 $P = 1/(Js+b)$、$C = k_p + k_i/s$:

$$G_d(s) = \frac{s}{Js^2 + (b+k_p)s + k_i}$$

### 三個頻段

| 頻段 | 近似 | 由誰決定 |
|---|---|---|
| 低頻 $\omega \ll$ | $G_d \approx s/k_i$(斜率 +20 dB/dec) | **$k_i$**:$k_i$ 每加 10 倍,低頻抑制多 20 dB |
| 中頻峰值 $\omega = \sqrt{k_i/J}$ | $\lvert G_d\rvert_{max} = 1/(b+k_p)$ | **$k_p$**:峰值高度與 $k_i$ 無關 |
| 高頻 | $G_d \approx 1/(Js) = P$ | 只有慣量;回授已無作用 |

峰值那一點分母實部 $k_i - J\omega^2 = 0$,$|G_d| = \omega/((b+k_p)\omega) = 1/(b+k_p)$;
本章 $k_p = 0.5$ → 峰值 1.96(+5.8 dB),**三種 $k_i$ 都一樣**,只是出現的頻率不同。

### 擾動解耦

若能量測(或以觀測器估測,第 10 章)負載轉矩 $\hat T_L$,直接加到控制器輸出:

$$u = u_{fb} + \hat T_L$$

理想情況下 $\hat T_L = T_L$,擾動在進入受控體前就被抵銷,回授只需處理殘差。
實際上 $\hat T_L$ 有延遲 $\tau$ 與增益誤差 $\epsilon$:殘差 = 延遲期間的全額擾動 + 之後 $\epsilon T_L$ 的穩態偏差(由積分器慢慢收拾)。

## 實驗設計

| 項目 | 設定 |
|---|---|
| 受控體 | $P(s) = 1/(Js+b)$,$J=0.002$、$b=0.01$ |
| 控制器 | PI,$k_p = 0.5$,$k_i \in \{1, 5, 20\}$ |
| 頻域 | `ct.feedback(P, C)` 即 $G_d$,0.1 ~ 1000 Hz,並畫受控體本身 $P$ 作為「無回授」參考 |
| 時域(連續) | t = 0.2 s 施加 0.1 Nm 步階負載(輸入 −0.1),`ct.forced_response`,0 ~ 2 s、4000 點 |
| 解耦(離散) | 1 kHz,`DiscretePID(0.5, 5)`,速度命令 1,t = 0.2 s 施加 0.1 Nm 負載;量測負載有 1 ms 延遲、增益 0.9(誤差 10%) |

### 實驗 1:擾動響應 Bode

比較 $k_i$ = 1、5、20 的 $|G_d(f)|$ 與開迴路 $P$。

### 實驗 2:步階負載時域

三種 $k_i$ 的速度偏差,記錄最大跌落。

### 實驗 3:擾動解耦

純回授 vs 回授 + 解耦前饋,比較 t ≥ 0.2 s 的最大速度跌落。

## 結果

| $k_i$ | 最大速度跌落 [rad/s] | $\lvert G_d(0.1\,\text{Hz})\rvert$ |
|---:|---:|---:|
| 1 | 0.1902 | −4.5 dB |
| 5 | 0.1779 | — |
| 20 | 0.1552 | −30.1 dB(漸近線 $20\log_{10}(2\pi \cdot 0.1/20)$ = −30.1 dB) |

| 解耦實驗 | 最大速度跌落 |
|---|---:|
| 純回授 | 0.1786 |
| 回授 + 解耦 | 0.0472(改善 3.8 倍) |

($\lvert G_d(0.1\,\text{Hz})\rvert$ 由 C++ 版印出;notebook 以 assertion 檢查,數值相同。)

- **峰值跌落只少約 18%,低頻抑制差 25.6 dB**:$k_i$ 從 1 加到 20,步階跌落只從 0.1902 降到 0.1552。
  這是因為步階擾動的瞬間峰值主要由 $k_p$ 決定 —— 上限大約是純 P 的 $0.1/(k_p+b) = 0.196$;
  但在 0.1 Hz,$k_i$ = 20 比 $k_i$ = 1 多抑制 25.6 dB(理論 $20\log_{10}20 = 26$ dB)。**$k_i$ 的主戰場是低頻。**
- **為何是 25.6 dB 而非 26.0 dB**:$s/k_i$ 近似要求分母中 $(b+k_p)s$ 項遠小於 $k_i$。
  在 0.1 Hz($\omega$ = 0.63 rad/s),$k_i$ = 1 時 $(b+k_p)\omega \approx 0.32$ 不可忽略,$|$分母$| \approx 1.05$,
  使 $|G_d|$ 比漸近線 −4.0 dB 再低約 0.4 dB;$k_i$ = 20 時該項相對很小,完全落在漸近線上(−30.1 dB)。
- **解耦的殘差來自延遲**:1 ms 內 0.1 Nm 全額作用在 $J$ = 0.002 上,速度掉 $0.1 \times 0.001 / 0.002 = 0.05$ rad/s,
  與量到的 0.0472 幾乎相同;之後的 10% 增益誤差只剩 0.01 Nm,由積分器慢慢消除。
- 純回授的離散模擬跌落 0.1786,與連續 $k_i$ = 5 的 0.1779 一致,兩種模擬方法互相印證。

## ✅ 驗證條件

| 條件 | 意義 |
|---|---|
| 跌落:$k_i$=1 > $k_i$=5 > $k_i$=20 | $k_i$ 越大跌落越小(但峰值差異有限) |
| $\lvert(G_d^{k_i=1} - G_d^{k_i=20})(0.1\,\text{Hz}) - 20\log_{10}20\rvert < 2$ dB | 低頻抑制與 $k_i$ 成正比 |
| $\lvert G_d^{k_i=20}(0.1\,\text{Hz}) - 20\log_{10}(2\pi \cdot 0.1/20)\rvert < 1.5$ dB | 低頻 $\lvert G_d\rvert$ 與 $s/k_i$ 漸近線吻合 |
| 解耦跌落 < 純回授跌落 / 2 | 解耦至少改善 2 倍 |

## 工程意義與常見誤區

- **「積分增益調大就能壓住擾動」只對了一半**:它只改善低頻;突發負載的瞬間峰值由 $k_p$(也就是頻寬)決定,
  而頻寬又受延遲、共振限制(第 4、16 章)。
- **擾動抑制要用頻率思考**:先問「擾動在什麼頻率?」—— 慢漂移靠 $k_i$、中頻衝擊靠頻寬、
  高於頻寬的擾動只能靠慣量或解耦。
- **解耦前饋的品質取決於量測延遲**:延遲越長,解耦在高頻的相位越錯,甚至可能放大擾動(練習 2)。
  增益誤差則相對寬容 —— 殘差由回授收拾。
- **量不到擾動怎麼辦?** 用觀測器從電流與速度估測負載轉矩(第 10、18 章),這是現代伺服驅動器的標配。
