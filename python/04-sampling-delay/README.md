## 一句話重點

數位控制器的延遲(ZOH 半拍 + 計算一拍 ≈ 1.5 $T_s$)不改變增益、只吃相位;在穿越頻率吃掉 $360° \cdot f_c \cdot 1.5T_s$ 的相位邊限,取樣率不夠高時,同一組增益就從「穩如泰山」變成「嚴重振鈴」。

## 學習目標

1. 理解數位控制的兩個延遲來源:**ZOH(半個取樣週期)**與**計算延遲(最多一個週期)**。
2. 量化延遲對相位邊限的侵蝕:$\Delta\phi = 360° \cdot f_c \cdot T_{delay}$。
3. 觀察取樣率不足時的振鈴與不穩定。
4. 用 **Padé 近似**把延遲放進連續模型,在 Bode 圖上直接看見相位被吃掉。

## 理論重點

### 延遲從哪裡來

```
 r ─►(+)─► [取樣 T] ─► [控制律計算] ─► [ZOH 保持] ─► [受控體] ─┬─► y
     ▲-                  └─ 計算延遲 ≈ 1T ─┘   └─ 平均 0.5T ─┘   │
     └──────────────────────────────────────────────────────────┘
```

- **ZOH**:輸出在一個週期內保持不變,等效於「平均晚了半拍」。ZOH 的頻率響應
  $\dfrac{1-e^{-sT}}{sT} = e^{-sT/2}\,\dfrac{\sin(\omega T/2)}{\omega T/2}$,相位部分正好是 $T/2$ 的純延遲。
- **計算延遲**:本拍取樣、算完後下一拍才更新輸出,最多一拍(本實驗以 `Delay(1)` 模擬)。

合計 $T_{delay} \approx 1.5\,T_s$。

### 延遲只吃相位

純延遲 $e^{-sT_d}$ 的 $|e^{-j\omega T_d}| = 1$、$\angle = -\omega T_d$,所以 Bode 圖上**震幅完全不變**、
相位隨頻率**線性**下墜(對數頻率軸上看起來越來越陡)。在穿越頻率 $f_c$ 處:

$$\Delta\phi = 360° \cdot f_c \cdot T_{delay} = 360° \cdot f_c \cdot \frac{1.5}{f_s}$$

經驗法則:$f_s \ge 20 f_c$ 時 $\Delta\phi \le 360 \cdot 1.5 / 20 = 27°$,延遲才算「可忽略」。

### Padé 近似

$e^{-sT_d}$ 不是有理函數,不能直接放進 `tf`。二階 Padé 近似:

$$e^{-sT_d} \approx \frac{1 - \frac{sT_d}{2} + \frac{(sT_d)^2}{12}}{1 + \frac{sT_d}{2} + \frac{(sT_d)^2}{12}}$$

它是全通濾波器($|\cdot| = 1$),在 $\omega T_d$ 不太大時相位與真延遲幾乎相同,可以直接交給 `margins()` 算 PM。

|---:|---:|
| 500 | 27.5 % |

| Padé 模型 | PM(`margins`) | 直線公式 PM |

| $f_s$ = 2000 Hz | 78.1° | 78.1° |

(Padé 的 PM 數值由 C++ 版印出;notebook 將它標在 Bode 圖圖例並以 assertion 檢查。)

- 同樣的 kp、ki,500 Hz 時 PM 從 89° 掉到 46°,overshoot 從 ~2% 暴增到 27.5%。
  500 Hz 只有穿越頻率的 12.6 倍,遠低於 20 倍經驗法則。
- 1000 Hz(25 倍)與 5000 Hz 的 overshoot 只差 0.2 個百分點:PM 67° 以上時閉迴路已經充分阻尼,
  **PM 與 overshoot 的關係高度非線性**,邊限在 45° 以下才會急劇惡化。
- 5000 Hz 的 1.6% 幾乎就是連續系統本身的 overshoot(連續響應最大值 ≈ 1.0157,
  來自 PI 零點與慢極點未完全抵銷的輕微過衝),延遲已可忽略。
- Padé 模型算出的 PM 與直線公式在 0.1° 內一致,證明「延遲只吃相位、吃掉 $\omega_c T_d$」的簡單公式在穿越頻率附近足夠準。

| 條件 | 意義 |

## 工程意義與常見誤區

- **「數位控制器 = 連續控制器離散化」是危險的簡化**:離散化本身可以很準(第 5 章),
  但 ZOH 與計算延遲是**結構性**的相位損失,設計時必須納入。
- **提高取樣率是最直接的解法**,但會受到 CPU 負載、ADC 速度、感測器更新率限制;
  其次是縮短計算延遲(例如取樣後立即計算、立即輸出,把 1T 壓到遠小於 1T)。
- **延遲的傷害與頻寬成正比**:同樣 1 ms 延遲,10 Hz 頻寬的迴路只損失 3.6°,100 Hz 的迴路損失 36°。
  高頻寬迴路(電流迴路、高性能伺服)對延遲最敏感。
- **不要只看 Bode 震幅**:延遲不改變 $|L|$,只看震幅圖會完全看不到它的影響。
