## 一句話重點

每多加一項都是交易:I 消除穩態誤差但吃相位,D 補相位讓你能用更高增益但放大雜訊;而 2-DOF 設定點加權(PID+)讓命令響應與擾動響應**分開調** —— 壓掉 overshoot 卻不犧牲一絲擾動抑制。

## 學習目標

1. 在同一受控體上比較 **P / PI / PID / PID+(2-DOF 設定點加權)**。
2. 理解每多加一項換到什麼、付出什麼:
   - P:簡單、頻寬受限、有穩態誤差(對速度迴路的擾動)
   - PI:消除穩態誤差,代價是相位損失與 overshoot
   - PID:D 項加相位、允許更高增益,代價是雜訊放大
   - PID+:設定點加權(b<1)壓 overshoot,不犧牲擾動抑制
3. 從開迴路 Bode 形狀解讀 I 項(低頻抬增益)與 D 項(中頻抬相位)的作用。

## 理論重點

### 四種控制律

$$u_{P} = k_p e, \qquad u_{PI} = k_p e + k_i\!\int e\,dt, \qquad u_{PID} = k_p e + k_i\!\int e\,dt + k_d \frac{de_f}{dt}$$

其中 $e = r - y$,$e_f$ 為經 100 Hz 一階低通後的誤差(D 項若不濾波,會把量測雜訊放大到不可用)。

### P 控制的穩態誤差

速度迴路受控體 $1/(Js+b)$ 沒有積分器,純 P 的穩態:

$$\omega_{ss} = \frac{k_p\,r - T_L}{k_p + b}$$

命令誤差 $b/(k_p+b)$ 很小(因為 $b$ 小),但**負載轉矩 $T_L$ 直接造成 $T_L/(k_p+b)$ 的速度落差**,且永不消失。

### 2-DOF 設定點加權(PID+)

```
        ┌── b·r ──►(+)─► [kp + kd·s] ──┐
 r ─────┤          ▲-                  ├─►(+)─u─► [P] ─┬─► y
        └──── r ──►(+)─► [ki/s] ───────┘               │
                   ▲-                                  │
 y ────────────────┴───────────────────────────────────┘
```

P 與 D 作用在 $b\,r - y$,I 作用在 $r - y$($b$ = `sp_weight`)。

- **回授路徑**(從 $y$ 看)仍是完整的 $C(s) = k_p + k_i/s + k_d s$ → 穩定性、邊限、擾動響應 $\frac{P}{1+CP}$ **完全不變**。
- **命令路徑**的前饋部分變成 $b k_p + k_i/s + b k_d s$ → 階躍瞬間的比例「踢」變小,overshoot 下降;
  穩態由積分器保證 $y \to r$,所以 $b<1$ 不會造成穩態誤差。

### 頻域形狀

- I 項:低頻 $|C| \to \infty$(每 decade +20 dB 抬高低頻增益)→ 消除穩態誤差,但在穿越附近帶來相位落後。
- D 項:在中頻加入最多 +90° 的相位超前 → 同樣 PM 下可以用更高的 kp、ki。

## 結果

| 控制器 | OS % | 命令穩態誤差 | 擾動跌落 | 最終誤差 |
|---|---:|---:|---:|---:|
| P(kp=0.5) | 0.0 | 0.0196 | 0.2157 | 0.2157 |
| PI(kp=0.5, ki=15) | 7.0 | −0.0000 | 0.1676 | 0.0000 |
| PID(kp=0.8, ki=25, kd=4m) | 6.3 | 0.0000 | 0.0889 | −0.0000 |
| PID+(2-DOF b=0.6) | 0.0 | −0.0000 | 0.0889 | −0.0000 |

| 開迴路 | PM | 穿越頻率 |
|---|---:|---:|
| P | 91° | 39.8 Hz |
| PI | 84° | 40.1 Hz |
| PID | 106° | 244.9 Hz |

(PM 由 C++ 版印出、notebook 標在 Bode 圖圖例;穿越頻率為以 notebook 同一組 `margins()` 另行計算的 `f_pm_hz`。)

- **P**:命令誤差 $b/(k_p+b) = 0.01/0.51 = 0.0196$;擾動後落到 $(0.5-0.1)/0.51 = 0.784$,
  誤差 0.2157 —— 與表中數字完全吻合,而且**永遠不會恢復**。
- **PI**:積分器把兩種穩態誤差都歸零,代價是 7% overshoot 與 PM 從 91° 降到 84°(I 項吃相位)。
- **PID**:D 項把 PM 抬到 106°,因此能把 kp 提高到 0.8、ki 提高到 25,擾動跌落從 0.1676 降到 0.0889(約減半)。
- **PID 的穿越頻率跳到約 245 Hz**:濾波後 D 項的高頻增益為 $k_d \cdot 2\pi \cdot 100 \approx 2.5$,
  控制器高頻增益 ≈ $0.8 + 2.5 = 3.3$,穿越頻率 ≈ $3.3/(2\pi J) \approx 264$ Hz 的量級。
  這個 106° 是**連續模型**的 PM;在 1 kHz 取樣下若照第 4 章扣掉 1.5 拍延遲,相位損失約 $360 \times 245 \times 1.5\text{ ms} \approx 132°$。
  本章時域模擬沒有放 `Delay(1)`,所以迴路仍然穩定 —— 實機上這組 kd 需要重新檢查(練習 1、4)。
- **PID+**:overshoot 從 6.3% 降到 0.0%,擾動跌落 **0.0889 完全不變** —— 2-DOF 只改命令路徑,回授路徑原封不動。

## ✅ 驗證條件

| 條件 | 意義 |
|---|---|
| P:擾動跌落 > 0.05 且 \|最終誤差\| > 0.05 | P 控制對負載擾動留下永久誤差 |
| PI:\|最終誤差\| < 0.005 | 積分作用消除擾動穩態誤差 |
| PID:\|最終誤差\| < 0.005 | 同上 |
| PID 擾動跌落 < PI 擾動跌落 | D 項換來的高增益提升擾動抑制 |
| PID+ overshoot < PID overshoot − 2% | 設定點加權有效壓 overshoot |
| \|PID+ 跌落 − PID 跌落\| < 0.01 | 且不犧牲擾動抑制 |

## 工程意義與常見誤區

- **「PID 一定比 PI 好」是誤解**:D 項對雜訊極度敏感(高頻增益 $k_d \cdot$ 濾波頻寬),
  在編碼器解析度低或雜訊大的系統上,D 項帶來的轉矩抖動可能比它的好處更糟(練習 1、2)。
- **不要用降低增益來壓 overshoot**:那會同時弄壞擾動抑制。命令響應的 overshoot 應該用
  設定點加權、命令整形或前饋(第 8 章)處理,回授增益留給擾動抑制與穩健性。
- **「overshoot 小 = 系統穩」不一定成立**:PID+ 的 overshoot 為 0,但它的 PM 與 PID 完全一樣。
  判斷穩定度要看回授路徑(邊限、擾動響應),不是命令響應。
- **D 項作用在誤差還是量測?** 本章 D 作用在 $b r - y$;實務上常令 D 只作用在 $-y$(等同 D 項的加權 $c=0$),
  以避免命令階躍造成的「微分踢」。
