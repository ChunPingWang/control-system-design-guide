## 一句話重點

迴路內的濾波器永遠是「**衰減換相位**」:它壓下雜訊或共振的同時,也在交越頻率吃掉相位邊限;
低通至少要放在迴路頻寬的 5~10 倍以上,已知頻率的干擾則改用 notch 精準下刀。

## 學習目標

1. 理解迴路內濾波器的鐵律:**衰減換相位**,而相位就是邊限。
2. 設計低通(壓感測雜訊)與 notch(壓共振,第 16 章會用)。
3. 量化濾波器造成的 PM 損失,學會「濾波頻率至少放在頻寬 5~10 倍以上」的法則。

## 理論重點

### 濾波器放在迴路的哪裡

```
r ──►(+)──► [C(s)] ──► [P(s)] ──┬──► y
     ▲-                          │
     └──────── [F(s)] ◄── 量測 ◄─┴── + 雜訊 n
```

回授路徑上的濾波器 $F(s)$ 直接成為迴路增益的一部分:$L(s) = C(s)P(s)F(s)$。
$F$ 在交越頻率 $\omega_c$ 的相位落後 $\angle F(j\omega_c)$ 會**一分不少地從相位邊限扣掉**:

$$PM_{\text{filtered}} \approx PM - |\angle F(j\omega_c)|$$

(濾波器在 $\omega_c$ 附近的增益也略微改變交越點,這是「約等於」的原因。)

### 二階 Butterworth 低通的相位代價

$$F(s) = \frac{\omega_f^2}{s^2 + \sqrt{2}\,\omega_f s + \omega_f^2}, \qquad
\angle F(j\omega) = -\arctan\frac{\sqrt2\,(\omega/\omega_f)}{1-(\omega/\omega_f)^2}$$

令 $x = \omega_c/\omega_f$:$x=0.2$(濾波頻率 = 5 倍頻寬)時相位落後約 16°;$x=0.8$ 時約 72°。
相位落後隨 $x$ 近似線性上升($\approx \sqrt2\,x$ rad),遠比增益衰減開始得早 —— 在 $\omega_c$ 處增益幾乎沒變,相位已經被吃了一大塊。這就是 5~10 倍法則的由來。

### Notch(帶拒)濾波器

$$N(s) = \frac{s^2 + \omega_0^2}{s^2 + (\omega_0/Q)\,s + \omega_0^2}$$

零點正好在 $\pm j\omega_0$,理論上該頻率增益為 0(深度 $-\infty$ dB);$Q$ 越大凹口越窄。
在 $\omega \ll \omega_0$ 時分子分母幾乎相等,相位只有 $-\arctan\!\big[(\omega\omega_0/Q)/(\omega_0^2-\omega^2)\big]$,
$Q=5$、$\omega/\omega_0=0.2$ 時僅約 2.4°。代價是:只對「已知且固定」的頻率有效,頻率漂移就失準。

### 一階離散低通與白雜訊

`OnePole` 以後向 Euler 實作 $y_k = y_{k-1} + \alpha (x_k - y_{k-1})$,$\alpha = a/(1+a)$,$a = 2\pi f_c T_s$。
對白雜訊的變異數縮減比為 $\alpha/(2-\alpha)$。

## 實驗設計

| 項目 | 設定 |
|---|---|
| 受控體 | 剛體 $P(s) = 1/(Js+b)$,$J=0.002$、$b=0.01$ |
| 控制器 | PI:$C(s) = 0.5 + 5/s$(交越約 $0.5/J = 250$ rad/s ≈ 40 Hz) |
| 低通 | 二階類比 Butterworth(`signal.butter(2, ..., analog=True)`),$f_c$ = 200 Hz、50 Hz |
| Notch | $f_0 = 200$ Hz、$Q=5$ |
| 雜訊實驗 | $f_s = 5$ kHz、1 s;速度量測加 $\sigma = 0.05$ rad/s 高斯雜訊(`default_rng(42)`);一階 200 Hz `OnePole` |

### 實驗 1:回授路徑低通的相位代價

比較 $L = CP$、$CP\cdot F_{200}$、$CP\cdot F_{50}$ 的 Bode 與 PM。

### 實驗 2:LPF vs notch

兩者都針對 200 Hz,比較 Bode 形狀、notch 深度(在 190~210 Hz 以 0.1 Hz 間隔掃描)與加入迴路後的 PM。

### 實驗 3:離散迴路內一階低通壓雜訊

速度 PI 追單位步階命令,量測含雜訊;比較「不濾」與「200 Hz 一階低通」時,0.5 s 後(穩態)轉矩命令的標準差。

## 結果

| 迴路 | PM | 相對無濾波的損失 |
|---|---:|---:|
| 無濾波 | 88.9° | — |
| LPF 200 Hz(5 倍頻寬) | 72.5° | 16.4° |
| LPF 50 Hz(1.2 倍頻寬) | 24.9° | 64.0° |
| Notch 200 Hz, Q=5 | 86.5° | 2.4° |

| 項目 | 數值 |
|---|---:|
| notch 深度 @200 Hz | −inf dB(掃描格點恰好落在 200.0 Hz,理想零點) |
| 轉矩雜訊 RMS(不濾) | 0.0251 |
| 轉矩雜訊 RMS(LPF 200 Hz) | 0.0082 |
| 改善倍數 | 3.1 倍 |

- 無濾波 PM 88.9°:在 40 Hz 處 PI 零點(10 rad/s)與受控體極點(5 rad/s)都已遠在下方,迴路近似純積分器 $250/s$。
- 200 Hz LPF 損失 16.4°,與上面 $x=0.2$ 的公式估算一致;50 Hz LPF 損失 64°,PM 只剩 24.9°,步階響應會嚴重振鈴,已接近不穩。
- Notch 同樣在 200 Hz 挖到底,但在 40 Hz 只吃 2.4° —— 比 LPF 省下 14°。
- 不濾時轉矩雜訊 ≈ $K_p\sigma = 0.5\times0.05 = 0.025$,與 0.0251 吻合;一階 200 Hz 低通的理論縮減 $\sqrt{\alpha/(2-\alpha)} \approx 0.33$($\alpha\approx0.20$),實測 0.0082/0.0251 ≈ 0.33。

## ✅ 驗證條件

| 條件 | 意義 |
|---|---|
| PM:無濾波 > LPF 200 > LPF 50 | 濾波頻率越低,相位代價越大 |
| LPF 50 Hz 的 PM < 30° | 濾波太靠近頻寬 → 邊限崩潰 |
| LPF 200 Hz 的 PM > 60° | 放在 5 倍頻寬 → 損失可控 |
| Notch PM > LPF 200 PM | notch 在交越處吃的相位較少 |
| notch 深度 < −15 dB | notch 確實挖出凹口 |
| 濾波後轉矩雜訊 < 不濾的一半 | 低通確實壓住量測雜訊 |

## 工程意義與常見誤區

- **「多加一級濾波讓訊號更乾淨」不是免費的**:每一級濾波都在交越處扣相位;要嘛降頻寬,要嘛接受振鈴。
- **濾波器的相位從很低的頻率就開始作用**:在 $\omega_f/5$ 時二階 Butterworth 的增益只差不到 0.01 dB,相位卻已落後 16°。只看增益曲線設計濾波器是常見錯誤。
- **Notch 只適合固定頻率**:機構共振會隨負載、位置漂移,窄 notch 對不準就沒效果,寬 notch(低 $Q$)相位代價又變大(練習 3)。
- **雜訊的去處**:不濾時,量測雜訊乘上 $K_p$ 直接進入轉矩命令(發熱、噪音、電流漣波);濾波把雜訊擋在迴路外,但也延遲了真實訊號。這是第 10、18 章用觀測器改善的出發點。
- **數位濾波還有取樣延遲**:本章相位代價以連續時間計算,實際離散實作要再加上第 4 章的延遲。
