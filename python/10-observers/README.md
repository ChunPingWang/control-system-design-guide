## 一句話重點

觀測器 = **模型預測 + 量測修正**:用受控體模型把已知輸入積分出狀態估測,再用「量測 − 預測」的創新量把估測拉回真值;
它能從一顆量化的位置感測器重建出比差分乾淨得多、且沒有差分延遲的速度。

## 學習目標

1. 建立 Luenberger 觀測器結構:**模型預測 + 量測修正**
   $\dot{\hat{x}} = A\hat{x} + Bu + L(y - C\hat{x})$。
2. 用極點配置(Ackermann / `control.place`)設計觀測器增益 $L$,並先檢查**可觀測性**。
3. 體會觀測器的核心價值:從**位置量測**重建**乾淨的速度**,並與有限差分比較。

## 理論重點

### 受控體狀態空間

剛體馬達 $J\dot\omega = T - b\omega$,狀態 $x = [\theta,\ \omega]^T$,輸入轉矩 $u=T$,只量位置:

$$A = \begin{bmatrix}0 & 1\\ 0 & -b/J\end{bmatrix},\quad
B = \begin{bmatrix}0\\ 1/J\end{bmatrix},\quad
C = \begin{bmatrix}1 & 0\end{bmatrix}$$

### Luenberger 觀測器

```
  u ──┬──────────────► [ 受控體 ] ──────────────► y(位置量測)
      │                                            │
      │      ┌───────────────────────────────┐     ▼
      └────► │ x̂̇ = A x̂ + B u + L (y − C x̂) │ ◄──(+)◄── −C x̂
             └───────────────┬───────────────┘
                             └──► x̂ = [θ̂, ω̂]  (ω̂ 即速度估測)
```

估測誤差 $\tilde x = x - \hat x$ 的動態:

$$\dot{\tilde x} = (A - LC)\,\tilde x$$

與輸入 $u$ 無關 —— 只要 $A-LC$ 穩定,任何初始誤差都會以 $A-LC$ 的極點速度衰減。
設計觀測器就是**選 $A-LC$ 的極點**。

### 可觀測性與極點配置

可觀測性矩陣 $\mathcal{O} = \begin{bmatrix}C\\ CA\end{bmatrix} = \begin{bmatrix}1&0\\0&1\end{bmatrix}$,秩 2 → 可任意配置觀測器極點。
(若只量速度,$\theta$ 不影響任何量測,系統就不可觀測。)

觀測器設計與狀態回授是**對偶**問題:$L = \text{place}(A^T, C^T, p)^T$(Ackermann 公式)。
本例可直接手算:

$$\det(sI - A + LC) = s^2 + (L_0 + b/J)\,s + (L_0\,b/J + L_1)$$

目標極點 $-200, -220$ → $s^2 + 420s + 44000$,$b/J = 5$ 得 $L_0 = 415$、$L_1 = 44000 - 5\cdot415 = 41925$。

### 差分速度的量化雜訊

編碼器量化步距 $q$,量化誤差近似均勻分佈(變異數 $q^2/12$)。差分 $(y_k - y_{k-1})/T_s$ 是兩個獨立量化誤差相減:

$$\sigma_{\text{fd}} \approx \frac{q}{\sqrt6\,T_s}$$

$T_s$ 越小、雜訊越大;觀測器則以其極點頻寬(約 200 rad/s)對量測低通,同時用模型「預測」補回相位,沒有差分的半拍延遲。

## 實驗設計

| 項目 | 設定 |
|---|---|
| 受控體 | `MotorPlant`:$J=0.002$、$b=0.01$ |
| 觀測器極點 | $-200, -220$ rad/s(略快於預期迴路頻寬 ~250 rad/s) |
| 取樣 | $f_s = 1$ kHz、1 s;觀測器以前向 Euler 離散 |
| 激發 | 開迴路轉矩 $u = 0.05\sin(2\pi\cdot 2t)$ N·m |
| 編碼器 | `EncoderModel(lines=2500)` → 10000 counts/rev,$q = 2\pi/10000 = 6.28\times10^{-4}$ rad |

### 實驗 1:從錯誤初值收斂

觀測器初始速度估測故意設為 $-2$ rad/s(真值 0),量測為無雜訊的連續位置,看誤差多快衰減。

### 實驗 2:量化位置下,差分 vs 觀測器

位置經編碼器量化後,分別以有限差分與觀測器取速度;比較 $k \ge 200$(0.2 s 後)兩者相對真實速度的誤差標準差。

## 結果

| 項目 | 數值 |
|---|---:|
| 可觀測性矩陣秩 | 2 |
| 觀測器增益 $L$ | $[415,\ 41925]$ |
| 驗證 $A-LC$ 極點 | $-200,\ -220$ |
| 初始速度誤差 | 2.00 rad/s |
| 後半段(0.5~1 s)最大誤差 | 0.02224 rad/s |

| 速度取得方式 | 誤差 RMS [rad/s] |
|---|---:|
| 有限差分 | 0.2574 |
| 觀測器 | 0.0321 |
| 改善倍數 | 8.0 倍 |
| 差分理論值 $q/(\sqrt6\,T_s)$ | 0.2565 |

- 手算 $L$ 與 `ct.place` 結果完全一致,極點精確落在 −200 / −220。
- 誤差時間常數約 $1/200 = 5$ ms,0.5 s 後理論上早已衰減到零;殘留的 0.022 rad/s 來自**離散化不一致**:受控體用半隱式 Euler(先更新 $\omega$ 再用新 $\omega$ 更新位置),觀測器用前向 Euler,兩者是略有不同的離散模型。
- 差分雜訊 0.2574 與理論 0.2565 相差 0.4%,證實它就是純量化雜訊;觀測器以約 200 rad/s 頻寬濾除大部分,降 8 倍。

## ✅ 驗證條件

| 條件 | 意義 |
|---|---|
| $A-LC$ 極點 = $\{-220, -200\}$(相對誤差 1e-6) | 極點配置正確 |
| 初始誤差 > 1.5 且後半段誤差 < 0.05 | 觀測器從大誤差收斂 |
| 觀測器速度誤差 RMS < 差分的 1/3 | 觀測器速度乾淨得多 |
| 差分雜訊 > $q/T_s/10$ | 差分雜訊量級符合量化理論 |

## 工程意義與常見誤區

- **觀測器不是濾波器的別名**:濾波器只處理量測,必然帶相位延遲;觀測器同時用「已知的輸入 $u$ + 模型」預測,在模型正確的頻段幾乎零延遲。這是第 18 章用觀測器速度回授提升增益的基礎。
- **觀測器極點不是越快越好**:越快越信任量測,量化雜訊穿透越多;越慢越信任模型,模型誤差(慣量、摩擦、未知負載)造成的偏差越大(練習 1、2)。經驗值是比控制迴路頻寬快 2~5 倍。
- **未知擾動會造成穩態偏差**:模型沒有負載轉矩,常值負載會讓速度估測偏移;把擾動當成額外狀態擴充進觀測器即可(練習 3,也是第 18 章的擾動觀測器)。
- **離散實作要跟受控體一致**:本章殘差 0.022 rad/s 就是離散化方法不同所致;實務上應以 ZOH 精確離散化設計觀測器。
- **先檢查可觀測性**:想估測的狀態若不影響量測,再怎麼調 $L$ 都估不出來。
