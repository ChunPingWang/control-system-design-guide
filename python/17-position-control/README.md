## 一句話重點

工業伺服的位置迴路幾乎都是**串級**:P 位置環輸出速度命令、PI 速度環輸出轉矩 ——
速度極限變成一個 clip、等速追隨誤差是乾淨的 $v/k_{p,pos}$,這些都是單迴路 PID 給不了的。

## 學習目標

1. 實作工業標準的**串級位置迴路**:P 位置環包 PI 速度環。
2. 理解串級的殺手級優點:**速度極限就是一個 clip**,飽和行為乾淨可控。
3. 比較單迴路 PID:性能可以接近,但約束處理與調機體驗差很多。
4. 驗證等速運動的**追隨誤差** $= v/k_{p,pos}$(kv 增益的由來)。

## 理論重點

### 串級結構

```
pos_ref ─►(+)─ kp_pos ─►[clip ±v_max]─►(+)─►[PI]─►[clip ±u_max]─► plant ─► pos
           ▲-                           ▲-                    │
           └────────────────────────────┴────────w────────────┘
```

受控體 $J\dot\omega = u - b\omega - T_L$,$\dot\theta = \omega$。
速度環 PI($k_p = 0.5$、$k_i = 5$)在 $J = 0.002$ 上的交越約 $k_p/J = 250$ rad/s(≈ 40 Hz);
位置環 $k_{p,pos} = 30$ rad/s(≈ 4.8 Hz),內外環頻寬比約 8:1,外環可把速度環當成「理想速度源」。

### 為什麼 P 位置環就夠

速度環已含積分器,位置環再多一個積分等於在 $\theta$ 之前有兩個積分;
P 位置環 + 理想速度環構成一階系統 $\dfrac{\Theta}{\Theta_{ref}} = \dfrac{k_{p,pos}}{s + k_{p,pos}}$ —— 步階響應沒有 overshoot。

### 追隨誤差(following error)與 kv

斜坡命令 $\theta_{ref} = vt$ 下,速度環的積分器讓實際速度精確等於 $v$,
所以位置環的輸出必須剛好是 $v$:

$$k_{p,pos}\,e_{ss} = v \quad\Rightarrow\quad e_{ss} = \frac{v}{k_{p,pos}}$$

$k_{p,pos}$ 在業界常稱 **kv**(速度增益,單位 1/s):追隨誤差與速度成正比、與 kv 成反比。
要消除它需要速度前饋(第 8 章),而不是加大 kv。

### 串級 = 某種 PID,但多了一個可以限制的中間變數

把串級展開,位置誤差到轉矩的等效控制器為 $(k_{p,v} + k_{i,v}/s)(k_{p,pos}\,e - s\theta)$,
展開後約相當於 $k_p \approx k_{p,v}k_{p,pos}$、$k_i = k_{i,v}k_{p,pos}$、$k_d = k_{p,v}$(微分作用在量測上)的 PID
—— 本例為 $k_p \approx 15$、$k_i = 150$、$k_d = 0.5$。
差別在於:串級有一個**物理意義明確的速度命令**可以 clip,單迴路 PID 沒有。

## 實驗設計

| 項目 | 設定 |
|---|---|
| 受控體 | `MotorPlant(J=0.002, b=0.01)`,1 kHz,模擬 2 s |
| 限制 | 速度極限 $V_{MAX} = 2$ rad/s,轉矩極限 $U_{MAX} = 1$ Nm |
| 串級 | 位置 P $k_{p,pos}=30$;速度 PI $(0.5, 5)$,輸出夾 ±1 Nm |
| 單迴路 PID | $k_p=15$、$k_i=20$、$k_d=0.5$,導數濾波 100 Hz,輸出夾 ±1 Nm |
| 擾動 | $t = 1.2$ s 起 0.05 Nm 負載轉矩 |

### 實驗 1:1 rad 步階 + 負載擾動

兩種架構追 1 rad 步階,記錄最大速度 $\max|\omega|$ 與擾動後的最大位置偏移。

### 實驗 2:斜坡追隨誤差

串級迴路追 1 rad/s 斜坡,$k_{p,pos} \in \{15, 30, 60\}$,取 $t \ge 1$ s 的平均誤差與 $v/k_{p,pos}$ 比較。

## 結果

| 架構 | $\max|\omega|$ [rad/s] | 擾動偏移 [mrad] |
|---|---:|---:|
| 串級(P/PI) | 2.03(極限 2.0) | 2.01 |
| 單迴路 PID | 18.30(未受控!) | 6.27 |

| $k_{p,pos}$ | 量測追隨誤差 | 理論 $v/k_{p,pos}$ |
|---:|---:|---:|
| 15 | 66.67 mrad | 66.67 mrad |
| 30 | 33.33 mrad | 33.33 mrad |
| 60 | 16.67 mrad | 16.67 mrad |

- **串級的速度波形是梯形**:位置誤差大時 $k_{p,pos}e$ 被夾在 2 rad/s,等速段貼著極限;
  2.03 只比極限多 1.5%,是速度環在 clip 轉折處的小 overshoot。
- **PID 衝到 18.3 rad/s**(極限的 9 倍):它沒有「速度」這個中間變數可以限制,轉矩一路飽和在 1 Nm 加速(500 rad/s²),衝到哪算哪。
- **擾動偏移串級只有 PID 的 1/3**:展開後串級的等效積分增益 $k_{i,v}k_{p,pos} = 150$,遠大於 PID 的 20;
  速度環的積分器在位置還沒明顯偏離前就開始補轉矩 —— 內環先擋。
- **追隨誤差與理論到小數第二位都相同**:速度環積分器讓等速段速度誤差精確為零,剩下的誤差完全由 $v/k_{p,pos}$ 決定。
  $k_{p,pos}$ 加倍,誤差減半。

## ✅ 驗證條件

| 條件 | 意義 |
|---|---|
| 串級 $\max|\omega| \le 1.05\,V_{MAX}$ | 串級尊重速度極限 |
| PID $\max|\omega| > 3\,V_{MAX}$ | 單迴路 PID 沒有速度概念 |
| 串級位置最大值 < 1.005 | 無 overshoot(梯形到位) |
| 串級最終誤差 < 1e-3、PID < 5e-3 | 兩者都能到位 |
| 串級擾動偏移 < PID | 串級剛性較好(內環先擋) |
| 三種 $k_{p,pos}$ 追隨誤差與 $v/k_{p,pos}$ 相差 < 15% | 追隨誤差 = $v/k_v$ |

## 工程意義與常見誤區

- **速度極限不是「調小增益」就能做到的**:單迴路 PID 要限制速度只能靠軌跡規劃;串級只要一個 clip,且在任何擾動下都成立。
- **追隨誤差是等速運動的必然結果**,不是 bug。多軸插補(例如 CNC 畫圓)時,各軸追隨誤差不同會造成輪廓誤差;
  解法是速度前饋(練習 1)讓追隨誤差趨近零,而不是無限拉高 kv。
- **外環不能比內環快**:$k_{p,pos}$ 拉太高,速度環跟不上速度命令,梯形波形變形甚至振盪。經驗值外環頻寬 ≤ 內環的 1/3~1/5(練習 2)。
- **調機順序由內而外**:先把速度環調好(第 3 章方法),再調位置環;單迴路 PID 的三個增益彼此耦合,沒有這個好處。
- **機構共振仍然是天花板**:速度環頻寬被第 16 章的共振限制住,位置環又必須比速度環慢,所以柔性機構的定位性能最終由機構決定(練習 4)。
